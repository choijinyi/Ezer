# 감정이 살아 움직이는 역사장편소설 스킬

이 폴더는 `SKILL.md`를 중심으로 구성된 **Agent Skills 형식의 재사용 가능한 소설 집필 패키지**입니다.

- 목표: 소설의 몰입과 감정(흥미·분노·슬픔·기쁨·통쾌함)을 실제 인물의 행동으로 생성.
- 특징: 고증을 지키면서도 가상 인물, 대화, 시간 압축, 극적 사건과 의도적인 재구성을 허용.
- 기본 프로젝트: 로버트 저메인 토머스와 제너럴셔먼호, 조선인·성경·널다리골교회의 연쇄 이야기.
- 설치: 스킬을 지원하는 에이전트의 해당 skills 디렉터리에 **폴더 전체**를 복사. 각 제품의 정확한 설치·호출 방법은 해당 제품 문서를 따름.
- ChatGPT 대화: ZIP을 참고 자료로 제공하거나 SKILL.md 내용을 지침으로 붙여 재사용 가능. 파일 자체를 내려받는 행위가 ChatGPT에 자동 설치되는 것은 아님.

참고: 2026년 Agent Skills 사양에서는 필수 `SKILL.md`와 YAML frontmatter의 `name`, `description` 필드를 사용합니다. https://agentskills.io/specification

우선 실행 예시: `토머스 소설 4부 32장 시놉시스를 감정 서사 중심으로 설계해줘.`
