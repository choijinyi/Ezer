# shorts-creator — 쇼츠제작

주제 한 문장(또는 초안 대본)에서 업로드 가능한 **세로형 쇼츠(9:16 · ≤60초)**까지.
youtube-video-pipeline의 축소·세로 특화판 오케스트레이터다 — 직접 일하지 않고
기둥 스킬을 쇼츠 규격으로 호출하고 게이트를 강제한다.

## 쇼츠 규격 (모든 하위 호출에 강제)

- 화면비 **9:16** (1080×1920) · 길이 **≤60초** · 자막 필수(무음 시청 전제)
- 구조: **훅(0–3초, 이탈 방지 한 문장) → 본론(3–50초, 1메시지 1영상) → CTA(마지막 5초)**
- 1영상 1메시지 — 본론에 논점이 2개 이상이면 분할을 제안한다

## 파이프라인 (기둥 호출 순서)

1. **대본** — 훅/본론/CTA 3블록 대본 작성 (읽기 속도 기준 초수 산정 병기)
2. **비주얼** — `media-gen-image` → `media-gen-video` (B-roll 클립, 세로 프레이밍 지시 필수)
3. **음성** — 나레이션 필요 시 TTS 벤더 스킬 (없으면 자막+음악만)
4. **합성** — `video-stitch` + `video-stitch-captions` (자막 번인·세로 안전 영역 준수)
5. **검증** — `video-verify-final-gate` (길이·화면비·오디오 싱크)

## 게이트 (비용 · HITL)

- 생성 호출은 **종량제 과금**이다 — 2단계(비주얼) 시작 전 대본과 예상 클립 수·개략 비용을
  보여주고 확인을 받는다(우회 금지). 대본 확정 전 생성 호출 금지.
- 산출물에 신뢰선: "AI 보조 생성 · 오너 검수 전".
- 실패한 단계는 그 단계만 재시도 — 성공한 산출물을 버리고 처음부터 다시 돌지 않는다.
