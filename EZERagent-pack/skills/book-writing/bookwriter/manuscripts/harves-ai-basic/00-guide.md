# 하베스 미용그룹 AI 역량 기본 교육 — 학생용 교재

> AI가 처음이어도 괜찮습니다. 이 교재는 '이론'을 외우는 책이 아니라, 여러분이 손으로 **직접 따라 하며 우리 샵에 바로 쓰는 결과물**을 만드는 워크북입니다. 한 장을 끝낼 때마다 멘트 하나, 사진 한 세트, 콘텐츠 한 개가 손에 남습니다.

---

## 이 교재는 누구를 위한 건가요

- **헤어샵 + OC 두피케어 전문점을 운영하는 원장님**을 위한 교재입니다.
- 블로그·숏츠를 '조금' 다뤄 본 정도면 충분합니다. 컴퓨터를 아주 잘 다루지 않아도 됩니다.
- 실습에는 **스마트폰과 노트북이 모두 필요합니다.** 사진·영상 촬영은 스마트폰으로, 글쓰기·디자인·영상 편집은 노트북으로 합니다.

---

## 이 교재를 보는 법 (각 장의 구성)

모든 장이 똑같은 순서로 되어 있습니다. 흐름만 익히면 13장 내내 편합니다.

| 표시 | 무엇을 하는 곳인가요 |
|---|---|
| **이 장에서 만들 결과물** | 이 장이 끝나면 손에 남는 것 (미리 봅니다) |
| **1. 먼저 알아두기 (읽기)** | 개념을 쉽게 풀어 읽는 부분. 부담 없이 읽으세요. |
| **2~3. 따라 하기** | 단계대로 직접 해 보는 부분. <span class="sec-tag">PROMPT</span> **복사용 프롬프트**(AI에게 주는 지시문)는 그대로 복사해 쓰면 됩니다. |
| <span class="sec-tag">WORKSHEET</span> **내 워크시트** | 빈칸(____)을 우리 샵 내용으로 채우는 칸. 여기를 채우면 그게 결과물입니다. |
| <span class="sec-tag">SKILL</span> **나만의 스킬로 저장하기** | 오늘 만든 걸 '한 번 만들어 계속 쓰는' 방법 |
| <span class="sec-tag">SAFETY</span> **꼭 지켜요** | 법·고객 신뢰를 지키는 안전 수칙. 가장 중요합니다. |
| <span class="sec-tag">SUMMARY</span> **이 장 핵심 요약** | 복습용 한눈 정리 |
| <span class="sec-tag">HOMEWORK</span> **집에서 해보기** | 다음 시간 전까지 해 볼 과제 |

> **프롬프트가 뭐예요?** AI에게 시키는 '말(지시문)'입니다. 이 교재의 프롬프트는 그대로 복사해 붙여넣고, `[ ]` 안의 글자만 우리 샵에 맞게 바꾸면 됩니다.

## 시작하기 전에 — 준비물

수업 첫날 헤매지 않으려면, 미리 아래를 준비해 오세요.

1. **스마트폰과 노트북** — 둘 다 꼭 가져오세요. (사진·영상 촬영은 스마트폰, 글쓰기·디자인·영상 편집은 노트북으로 하면 훨씬 수월합니다.)
2. **AI 계정 1~2개** — 아래 '도구 한눈에 보기'를 참고해 **무료로 가입**하면 됩니다. 구글 계정(Gemini용)과 글쓰기 AI(Claude) 하나면 대부분 됩니다.
3. **우리 샵 정보 메모** — 샵 이름, 대표 시술 3개와 가격, 위치(동네), 강점 한두 가지.
4. **시술 사진 몇 장** — 전·후가 있으면 좋아요. (3강에서 씁니다. **고객 게시 동의**를 받은 사진이면 더 좋습니다.)

> **유료를 꼭 써야 하나요?** 아닙니다. 거의 모든 실습은 **무료로** 됩니다. 무료 사용량을 다 쓰면 잠시 기다리거나 다른 AI로 바꿔 쓰면 됩니다. 유료는 더 편할 뿐 필수가 아닙니다. (단, 6강의 영상 '생성' 도구 구글 Flow는 유료입니다 — 그 부분은 '해 보면 좋은 선택'입니다.)

## 우리가 쓰는 AI 도구 한눈에 보기

도구는 많이 아는 것보다 **작업별로 하나씩 잘 쓰는 게** 낫습니다. 이 교재는 작업마다 '메인 하나 + 대안'만 권합니다.

| 무슨 일을 할 때 | 메인 도구 | 대안 | 비용 |
|---|---|---|---|
| **글쓰기** (멘트·캡션·소개글·대본·메시지) | **Claude**(클로드) | ChatGPT / 네이버 글은 클로바X | 무료로 가능 |
| **조사·리서치** (상권·트렌드·경쟁·사례) | **ChatGPT 또는 Gemini의 심층 리서치(Deep Research)** | — | 일부 무료 / 더 쓰려면 유료 |
| **이미지** (예시컷·제품컷·배경 정리) | **Gemini 나노 바나나** | — | 무료로 가능 |
| **디자인** (카드뉴스·가격표·썸네일) | **미리캔버스 / Canva** | — | 무료로 가능 |
| **영상 만들기** (AI 인트로 클립) | **구글 Flow** | — | 유료(구독) |
| **영상 편집** (컷·자막) | **CapCut**(캡컷) | Vrew(자막) | 무료로 가능 |
| **데이터 해석** (캡처 화면 읽기) | **Claude·ChatGPT·Gemini** (셋 다 가능) | — | 무료 범위 내 |
| **나만의 스킬** (반복 작업 저장) | **Claude 프로젝트 / ChatGPT 맞춤형 GPT** | 무료는 '메모에 저장' | 무료로 가능 |

> 각 도구의 무료/유료 조건은 자주 바뀝니다. 그날그날 화면에서 확인하세요.

> **'나만의 스킬'이 뭐예요?** 매번 긴 지시문을 새로 쓰지 말고, **우리 샵 정보·말투·금지 표현을 한 번 담아 저장해 두고 계속 부르는 '나만의 AI 비서'**입니다. 무료로는 메모장에 저장해 붙여넣고, 유료 플랜이면 'Claude 프로젝트'나 'ChatGPT 맞춤형 GPT'로 등록합니다. 5강에서 직접 하나 만들어 봅니다.

## <span class="sec-tag">SAFETY</span> 우리의 안전 약속 (모든 장에서 지킵니다)

AI는 강력하지만, 잘못 쓰면 **법(화장품법·광고법)**과 **고객 신뢰**를 한 번에 잃습니다. 아래 여섯 가지는 13장 내내 반복되는 약속입니다. 지금 한 번 읽어 두세요.

1. **효능을 단정하지 않습니다.** OC는 화장품입니다. '탈모 치료', '발모', '모발 재생' 같은 의약품 오인·효능 단정 표현은 금지입니다. (식약처에 보고된 기능성화장품의 '탈모 증상 완화에 도움' 표현은 **본사 확인 후에만** 씁니다.)
2. **시술 결과를 AI로 꾸미지 않습니다.** Before/After·영상에서 보정은 **밝기·색감까지만**입니다. AI로 결과를 더 좋아 보이게 만들면 허위·과장 광고입니다.
3. **고객 사진·후기는 동의를 받습니다.** 게시 전 동의를 받고, 내려 달라고 하면 즉시 내립니다.
4. **대가를 받은 콘텐츠는 표기합니다.** 무상 제공·할인 등 대가가 있으면 '광고/협찬'을 밝힙니다.
5. **고객 개인정보를 AI에 넣지 않습니다.** 이름·연락처·예약자 명단은 가리거나 '○○님' 빈칸으로 씁니다.
6. **AI 답은 확인하고 씁니다.** AI는 가끔 틀린 말을 자신 있게 합니다. 특히 규정·숫자·사실은 사람이 최종 확인합니다. **"AI가 괜찮다고 했어요"는 면책 사유가 아닙니다.**
