# 과정 총괄 · 학습 경로

## 1. 과정 개요

| 항목 | 내용 |
|---|---|
| 과정명 | 생성형 AI 콘텐츠 제작 실무 (전사교육) |
| 교육 대상 | CBS M&C 핵심 직원 10명 |

| 교육 목표 | AI 기술 기초 이해 · 생성형 AI 도구 활용 능력 확보 · AX(AI 전환) 필요성 인지 |

| 후속 과정 | 핵심역량교육 「AI 뉴스 콘텐츠 자동화 실무」 (80H) |

## 2. 학습 경로

전사교육은 CBS M&C AI 역량 강화 로드맵의 출발점이다. 각 단계의 산출물이 다음 단계의 입력이 되는 순환 구조다.

```
전사교육 40H        핵심역량교육 80H        PoC(현업 검증)        AX 실행계획
이해·기초     ──▶    자동화·실무      ──▶    피드백 루프 3회전  ──▶  전사 확산
```

본 과정에서 발굴한 **AI 적용 지점**과 8~9회차에서 만든 **프로토타입**이 핵심역량교육의 실제 자동화 과제(PBL·CBL)로 이어진다.

## 4. 교육 방법

- **실무 밀착** — CBS M&C의 실제 업무(노컷TV 채널, 뉴스 영상 아카이브, 기사 DB, 편집 워크플로우)를 교육 소재로 삼아 교육과 현업의 거리를 좁힌다.
- **이론과 실습의 균형** — 각 회차는 "왜 그런가(개념)"와 "어떻게 하는가(실습)"를 함께 다룬다.
- **PBL·CBL** — 8~10회차는 실제 업무 과제를 다루는 적용 워크숍과 발표로 구성해, 학습이 현업 적용으로 수렴하게 한다.
