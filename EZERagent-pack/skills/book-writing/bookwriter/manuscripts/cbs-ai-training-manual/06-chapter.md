# 6회차 · 업무 자동화 시나리오 설계

| 회차 | 시간 | 구성 | 선수 지식 |
|---|---|---|---|
| 6 / 10 | 4H | 핵심 개념 · 시나리오 설계 · 실습 3종 | 2~5회차(개별 작업) |

## 학습 목표

이 회차를 마치면 다음을 할 수 있다.

- 어떤 업무가 자동화에 적합한지 기준으로 판단할 수 있다.
- 트리거 → 단계 → 액션의 흐름으로 자동화를 설계하는 사고법을 익힌다.
- 워크플로우 자동화 도구의 종류와 역할을 구분할 수 있다.
- 사람이 반드시 개입해야 하는 **검수 지점**을 포함한 시나리오를 설계할 수 있다.

---

## 1. 핵심 개념

### 1.1 무엇을 자동화할 것인가

**[개념]** 모든 일을 자동화할 필요는 없다. 아래 세 조건을 많이 만족할수록 좋은 자동화 후보다.

| 기준 | 설명 |
|---|---|
| 반복적 | 매번 비슷한 순서로 한다 |
| 규칙적 | 판단 기준이 명확하다 |
| 빈도·양이 많다 | 자주, 혹은 대량으로 한다 |

반대로 **창의적 판단·민감한 결정**(예: 보도 여부, 표현 수위)은 자동화 대상이 아니라 사람이 한다.

### 1.2 자동화 사고법: 트리거 → 단계 → 액션

**[개념]** 자동화는 "어떤 일이 생기면(트리거), 정해진 단계를 거쳐, 결과를 만든다(액션)"의 구조다.

```
[트리거] 새 보도자료가 메일함에 도착
   → [단계1] 본문 추출
   → [단계2] AI로 기사 초안 생성(2회차 템플릿)
   → [단계3] AI로 요약·제목 후보 생성
   → [검수] 사람이 확인·수정   ← 반드시 사람
   → [액션] 초안 문서를 담당자에게 전달
```

### 1.3 워크플로우 자동화 도구

**[개념]** 코딩 없이 여러 앱과 AI를 블록처럼 연결하는 도구들이다.

| 도구 | 특징 | 비고 |
|---|---|---|
| n8n | 오픈소스·자체 호스팅 가능, AI 노드 풍부 | 데이터 통제·맞춤 강점 |
| Make | 시각적 흐름 설계, 다양한 연동 | 직관적 |
| Zapier | 가장 많은 앱 연동, AI 액션 | 입문 친화 |
| Power Automate | MS 365 환경 연동 | 사내 오피스 연계 |

**[팁]** 도구 선택보다 **흐름 설계**가 먼저다. 종이에 트리거–단계–액션을 그린 뒤 도구로 옮긴다.

### 1.4 사람이 개입하는 지점(검수 게이트)

**[주의]** 방송·뉴스 자동화의 핵심 원칙: **발행 직전에는 반드시 사람의 검수 게이트를 둔다.** AI가 만든 기사·자막·이미지가 사람 확인 없이 외부로 나가는 흐름은 만들지 않는다. 자동화는 *초안까지*, 발행 판단은 *사람*이다.

---

## 2. 자동화 시나리오 설계

### 2.1 시나리오 설계 캔버스

자동화를 설계할 때 아래 칸을 채운다.

| 항목 | 내용 |
|---|---|
| 목표 | 무엇을 줄이려는가(시간·실수 등) |
| 트리거 | 무엇이 흐름을 시작시키나 |
| 단계 | 순서대로의 처리 |
| 사용 도구 | 각 단계에 쓰는 AI·앱 |
| 검수 지점 | 사람이 확인하는 위치 |
| 예외 처리 | 실패·이상 시 어떻게 |

### 2.2 예시 — 보도자료 처리 자동화

| 항목 | 내용 |
|---|---|
| 목표 | 보도자료 → 기사 초안까지의 시간 단축 |
| 트리거 | 지정 메일함에 보도자료 수신 |
| 단계 | 본문 추출 → 기사 초안 → 요약·제목 후보 → 썸네일 콘셉트 |
| 도구 | 자동화 도구 + LLM + 이미지 도구 |
| 검수 지점 | 기사 초안·제목 확정 전 데스크 검수 |
| 예외 | 첨부 형식 오류 시 담당자 알림 |

### 2.3 예시 — 영상 업로드 후처리 자동화

영상 업로드(트리거) → 자동 자막 생성 → 숏폼 후보 추출 → 제목·태그·해시태그 초안(7회차) → **담당자 검수** → 발행. 노컷TV 운영에 직접 연결되는 시나리오다.

## 3. 실습

### [실습 1] 내 반복 업무 자동화 후보 찾기 (30분)

본인 업무를 5개 적고, 1.1 기준으로 점수를 매겨 자동화 우선순위를 정한다.

| 업무 | 반복성(1~5) | 규칙성(1~5) | 빈도(1~5) | 합계 |
|---|---|---|---|---|
| | | | | |
| | | | | |

### [실습 2] 자동화 시나리오 1개 설계 (50분)

합계 점수가 가장 높은 업무로 2.1 캔버스를 채운다. **검수 지점**을 반드시 포함한다. 완성한 캔버스는 8~9회차 워크숍의 입력 자료로 사용한다.

### [실습 3] 미니 자동화 만들어 보기 (40분)

자동화 도구로 아주 단순한 흐름 하나를 직접 만들어 본다(예: "양식 제출 → AI 요약 → 시트에 기록"). 코딩 없이 블록을 연결하는 감각을 익히는 것이 목적이다.

**[팁]** 처음부터 거창하게 만들지 않는다. **한 단계짜리 자동화**부터 성공시키고 늘려 간다.

## 4. 체크리스트

- [ ] 자동화에 적합한 업무의 3가지 기준을 설명할 수 있다.
- [ ] 트리거–단계–액션 구조로 흐름을 그릴 수 있다.
- [ ] 워크플로우 자동화 도구의 역할을 구분할 수 있다.
- [ ] 검수 게이트를 포함한 시나리오를 설계했다(실습 2).
- [ ] 단순 자동화 흐름을 직접 하나 만들어 봤다(실습 3).

## 5. 핵심 요약

- 자동화 후보는 **반복·규칙·다빈도** 업무다. 창의·민감 판단은 사람이 한다.
- 자동화는 **트리거 → 단계 → 액션** 구조로 설계한다.
- 도구보다 **흐름 설계**가 먼저이며, 발행 전 **사람 검수 게이트**는 필수다.
- 보도자료 처리·영상 후처리는 CBS M&C에 바로 적용 가능한 시나리오다.
