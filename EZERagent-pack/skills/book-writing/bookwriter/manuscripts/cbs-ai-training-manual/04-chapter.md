# 4회차 · AI 기반 이미지·음성 콘텐츠 제작

| 회차 | 시간 | 구성 | 선수 지식 |
|---|---|---|---|
| 4 / 10 | 4H | 핵심 개념 · 도구 비교 · 실습 3종 | 2회차(프롬프트 기초) |

## 학습 목표

이 회차를 마치면 다음을 할 수 있다.

- AI 이미지 생성의 기본 원리와 주요 도구의 차이를 설명할 수 있다.
- 피사체·스타일·구도·분위기를 포함한 이미지 프롬프트를 작성할 수 있다.
- AI 음성 합성(TTS)으로 내레이션을 만들고 품질을 평가할 수 있다.
- 썸네일·배너·내레이션 제작에서 **저작권·초상권·음성권** 위험을 점검할 수 있다.

---

## 1. 핵심 개념

### 1.1 AI 이미지 생성은 어떻게 작동하나

**[개념]** 텍스트로 그림을 그리는 모델(text-to-image)은 1회차에서 본 **디퓨전 모델**을 쓴다. 무작위 노이즈에서 출발해, "이 글(프롬프트)에 맞는 그림"이 되도록 노이즈를 단계적으로 걷어낸다. 그래서 같은 프롬프트라도 매번 조금씩 다른 결과가 나온다.

### 1.2 이미지 생성 도구 비교

| 도구 | 강점 | 상업적 사용 | 한국어 프롬프트 | 비고 |
|---|---|---|---|---|
| Midjourney | 미적 완성도 높음 | 유료 플랜 시 가능 | 영어 권장 | 감각적 비주얼 |
| DALL·E (ChatGPT 내) | 대화형, 수정 쉬움 | 가능 | 양호 | 아이디어 빠른 시안 |
| Adobe Firefly | **상업 안전성** 강조(라이선스 학습) | 가능 | 양호 | 방송·상업용에 유리 |
| Stable Diffusion | 무료·로컬 실행, 커스터마이즈 | 라이선스 확인 필요 | 영어 권장 | 고급/대량 작업 |
| Google Imagen | 텍스트 표현·사실감 | 가능 | 양호 | 구글 생태계 연동 |

**[주의]** "상업적 사용 가능"은 도구마다, 요금제마다 다르다. **방송·공개 콘텐츠에 쓸 이미지는 라이선스 조건을 반드시 확인**한다. 상업 안전성이 중요한 작업은 Firefly처럼 라이선스 학습을 표방하는 도구가 안전하다.

### 1.3 이미지 프롬프트 작성법

**[개념]** 좋은 이미지 프롬프트는 다음 요소를 포함한다.

| 요소 | 예시 |
|---|---|
| 피사체 | "마이크를 든 뉴스 앵커" |
| 스타일 | "사실적 사진 / 플랫 일러스트 / 3D 렌더" |
| 구도·앵글 | "정면 클로즈업 / 부감 / 여백 왼쪽" |
| 조명·색감 | "스튜디오 조명, 푸른 톤" |
| 분위기·용도 | "신뢰감 있는, 유튜브 썸네일용" |

> 예: "신뢰감 있는 분위기의 뉴스 스튜디오, 정면 구도, 오른쪽에 텍스트 넣을 여백, 사실적 사진 스타일, 16:9"

### 1.4 AI 음성 합성(TTS)

**[개념]** TTS(Text-to-Speech)는 글을 사람 목소리로 바꾼다. 최근 모델은 억양·감정·호흡까지 자연스럽다. 특정 화자의 목소리를 학습해 재현하는 **음성 클로닝**도 가능하다.

| 도구 | 강점 | 한국어 | 비고 |
|---|---|---|---|
| ElevenLabs | 자연스러움·다국어·감정 표현 | 우수 | 글로벌 표준급 |
| Supertone(슈퍼톤) | 한국어 품질·방송 활용 | 우수 | 사내 활용 경험 보유 |
| Typecast | 캐릭터 음성·간편 | 우수 | 영상 더빙 친화 |
| Naver Clova Voice | 안정적 한국어·API | 우수 | 국내 서비스 연동 |

**[주의] 음성권·초상권** — 실존 인물의 목소리·얼굴을 동의 없이 학습·재현하면 법적·윤리적 문제가 된다. 진행자·성우의 음성 클로닝은 **반드시 당사자 동의**를 받는다. 뉴스에서 AI 음성·이미지를 쓸 때는 사내 고지 기준을 따른다.

## 2. 업무 적용 워크플로우

### 2.1 썸네일·배너 제작 흐름

| 단계 | 내용 |
|---|---|
| ① 콘셉트 | 제목·키워드에서 비주얼 콘셉트 도출(2회차 프롬프트 활용) |
| ② 생성 | 이미지 도구로 시안 4~6종 생성 |
| ③ 선별 | 가독성·브랜드 적합성으로 1~2종 선택 |
| ④ 편집 | 텍스트·로고·자막을 편집툴에서 합성 |
| ⑤ 검수 | 저작권·오해 소지·인물 묘사 점검 |

### 2.2 내레이션 더빙 흐름

대본(2~3회차 결과) → TTS로 음성 생성 → 속도·억양·끊어 읽기 조정 → 영상에 동기화(5회차) → 검수.

## 3. 실습

### [실습 1] 영상 썸네일 3종 생성 (40분)

실제 콘텐츠 제목 하나를 골라 1.3 방식으로 프롬프트를 작성하고, 도구로 시안 3종을 만든다. 아래 기준으로 평가해 1종을 고른다.

| 기준 | 시안 A | 시안 B | 시안 C |
|---|---|---|---|
| 주제 전달력 | | | |
| 텍스트 넣을 여백 | | | |
| 브랜드 적합성 | | | |
| 저작권·오해 소지 | | | |

### [실습 2] 뉴스 요약 내레이션 만들기 (40분)

2회차에서 만든 요약문을 TTS로 음성화한다. 같은 문장을 두 가지 목소리/속도로 만들어 비교하고, "방송에 쓸 만한가"를 평가한다.

| 항목 | 음성 A | 음성 B |
|---|---|---|
| 발음 정확성 | | |
| 자연스러운 억양 | | |
| 끊어 읽기·호흡 | | |

**[팁]** 숫자·고유명사·외래어는 TTS가 잘못 읽는 경우가 많다. 대본에 발음을 한글로 풀어 적거나(예: "AI → 에이아이"), 끊어 읽기 기호를 넣으면 개선된다.

### [실습 3] 카드뉴스 배너 만들기 (40분)

뉴스 한 건을 카드뉴스 1장으로 만든다. 이미지 생성 + 텍스트 합성까지 진행하고, 저작권·사실 왜곡 여부를 점검표로 확인한다.

## 4. 체크리스트

- [ ] 이미지 생성 도구 3종 이상의 차이(특히 상업적 사용)를 설명할 수 있다.
- [ ] 피사체·스타일·구도·분위기를 포함한 이미지 프롬프트를 작성했다.
- [ ] TTS로 내레이션을 만들고 두 음성을 비교 평가했다(실습 2).
- [ ] 음성 클로닝에는 당사자 동의가 필요함을 이해했다.
- [ ] 생성물의 저작권·초상권·오해 소지를 점검하는 습관을 익혔다.

## 5. 핵심 요약

- 이미지 생성은 디퓨전 원리로, 프롬프트에 **피사체·스타일·구도·분위기**를 담을수록 좋다.
- 도구마다 **상업적 사용 조건**이 다르므로 방송용은 라이선스를 반드시 확인한다.
- TTS는 자연스러워졌지만 숫자·고유명사 오독에 주의하고, **음성권·초상권**을 지킨다.
- AI 생성물도 발행 전 검수(저작권·왜곡·고지) 대상이다.
