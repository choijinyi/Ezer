# 7회차 · 데이터 분석·시각화 AI 활용

| 회차 | 시간 | 구성 | 선수 지식 |
|---|---|---|---|
| 7 / 10 | 4H | 핵심 개념 · 업무 워크플로우 · 실습 3종 | 2회차(프롬프트), 6회차(자동화) |

## 학습 목표

이 회차를 마치면 다음을 할 수 있다.

- 콘텐츠 성과를 나타내는 주요 지표를 이해하고 자연어로 데이터를 분석할 수 있다.
- AI로 제목·설명·태그·해시태그(SEO 패키지)를 생성하고 다듬을 수 있다.
- 키워드·트렌드 분석으로 콘텐츠 소재를 발굴할 수 있다.
- 발행 → 성과 측정 → 개선으로 이어지는 데이터 루프를 설계할 수 있다.

---

## 1. 핵심 개념

### 1.1 데이터로 콘텐츠를 개선한다는 것

**[개념]** "감(感)"이 아니라 숫자로 판단하면 개선이 빨라진다. 콘텐츠 성과를 보는 대표 지표는 다음과 같다.

| 지표 | 의미 | 개선 방향 |
|---|---|---|
| 노출·검색 유입 | 얼마나 발견되나 | 제목·태그·SEO |
| 클릭률(CTR) | 노출 대비 클릭 | 썸네일·제목 |
| 시청 지속률 | 끝까지 보나 | 도입부·편집·길이 |
| 좋아요·댓글·공유 | 반응·확산 | 주제·소통 |

### 1.2 AI 데이터 분석 도구

**[개념]** 이제는 함수·코드를 몰라도 **자연어로 데이터에 질문**할 수 있다.

| 도구 | 활용 |
|---|---|
| ChatGPT(데이터 분석) | 표 파일 올리고 "어떤 영상이 시청 지속률이 높아?"처럼 질문, 차트 생성 |
| Gemini | 구글 시트·문서 연동 분석 |
| 스프레드시트 내 AI 기능 | 시트에서 바로 요약·분류·수식 제안 |

**[주의]** AI의 분석도 틀릴 수 있다. **숫자의 출처와 계산 기준**을 확인하고, 이상한 결론은 원자료로 검증한다.

### 1.3 SEO·제목·태그·해시태그 자동 생성

**[개념]** 검색·추천 알고리즘은 제목·설명·태그의 키워드를 본다. AI로 후보를 여러 개 만들어 **A/B로 비교·선택**한다.

| 항목 | AI 활용 |
|---|---|
| 제목 | 클릭 유도형·정보형 등 후보 5개 생성 |
| 설명 | 핵심 키워드를 자연스럽게 포함한 설명문 |
| 태그·해시태그 | 주제 관련·트렌드 키워드 추출 |

> **[주의] 낚시 금지** — 클릭을 위해 내용과 다른 제목(낚시)을 쓰면 신뢰를 잃는다. 뉴스에서는 **사실에 부합하는 매력적 제목**이 원칙이다.

### 1.4 뉴스 트렌드 분석과 소재 발굴

**[개념]** 검색량·실시간 키워드·SNS 트렌드를 분석하면 "지금 사람들이 궁금해하는 것"을 빠르게 찾는다. 이는 **1회차에서 확인한 가장 큰 병목 — 소재 탐색(전체 시간의 30~50%) — 을 직접 줄이는 활동**이다.

## 2. 업무 워크플로우

### 2.1 영상 메타데이터 최적화

업로드 전: 제목 후보 5개 → 설명문 → 태그·해시태그 → 썸네일(4회차)과 함께 점검 → 발행. 6회차 자동화 흐름의 마지막 단계로 붙일 수 있다.

### 2.2 트렌드 기반 소재 발굴

이번 주 키워드·이슈 수집 → AI로 우리 채널 적합 소재로 변환 → 우선순위 → 기획안 초안. 소재 회의의 출발 자료가 된다.

### 2.3 성과 분석 루프

| 단계 | 내용 |
|---|---|
| 발행 | 콘텐츠 공개 |
| 수집 | 지표 데이터 모으기 |
| 분석 | AI로 "무엇이 잘됐나/아쉬웠나" 분석 |
| 개선 | 다음 콘텐츠에 반영 |

### 2.4 데이터 시각화

분석 결과를 표·차트로 만들면 팀 공유가 쉽다. AI에게 "이 데이터를 막대그래프로, 핵심 한 줄 요약과 함께"처럼 요청한다.

## 4. 체크리스트

- [ ] 콘텐츠 주요 지표(노출·CTR·지속률·반응)를 설명할 수 있다.
- [ ] 데이터 표를 AI로 분석해 인사이트를 도출했다(실습 1).
- [ ] 제목·설명·태그·해시태그 패키지를 생성·선택했다(실습 2).
- [ ] 트렌드 분석으로 소재 10개를 발굴했다(실습 3).
- [ ] 낚시성 제목을 피하고 사실 기반 매력 제목을 쓰는 원칙을 이해했다.

## 5. 핵심 요약

- 콘텐츠는 **지표(노출·CTR·지속률·반응)**로 개선 방향을 찾는다.
- 이제 코드 없이 **자연어로 데이터를 분석**할 수 있으나, 결과는 원자료로 검증한다.
- SEO 패키지는 후보를 만들어 비교·선택하되, **낚시 금지** 원칙을 지킨다.
- 트렌드 분석은 가장 큰 병목인 **소재 탐색 시간을 직접 줄인다.**
