# SECURITY.md

bookwriter는 사용자가 출판 전 미공개 원고를 업로드하는 시스템이다. **비밀 유지가 1차 보안 목표**다.

## 위협 모델

| 위협 | 영향 | 대응 |
|---|---|---|
| 다른 사용자가 내 원고를 본다 | 신뢰 붕괴 | job-id 무작위(UUIDv7), 사용자 인증, ACL |
| 우리 시스템이 원고를 학습 데이터로 쓴다 | 평판 / 법적 | AI Gateway zero-data-retention 모델만 |
| 보관 중 원고가 유출 | 동상 | Blob 비공개 + 짧은 TTL + 서명 URL |
| 악의적 PDF로 RCE | 인프라 장악 | Vercel Sandbox로 PDF 파싱 격리 |
| 인용/링크 통한 SSRF | 내부 메타데이터 노출 | URL 화이트리스트, fetch에서 사설 IP 차단 |
| 프롬프트 주입으로 다른 사용자 데이터 누출 | 비밀 누출 | 시스템 프롬프트에 작업 컨텍스트만 주입, 작업 격리 |
| 업로드 폭탄 (zip bomb, 거대 PDF) | DoS | 입력 크기/파싱 시간 상한 |

## 비밀 관리

- 모든 비밀은 `vercel env`로 관리 (절대 `.env`를 커밋하지 않는다).
- AI Gateway 키, Blob 토큰은 서버 전용. 클라이언트 노출 금지.
- 로컬 개발은 `vercel env pull` 후 `.env.local` (gitignore).

## 인증

- 게스트: job-id 쿠키로 1회 무료. 만료 시 새 키 발급.
- 인증 사용자: Clerk (Marketplace).
- 관리자 도구: 별도 OAuth, MFA 강제.

## 데이터 라이프사이클

```
업로드 → build/<job>/ (사용자 인증 필요)
       ↓ 7일
     자동 삭제 (cron)

산출물 → dist/<job>/ (사용자 인증 필요)
       ↓ 30일 (보관 신청 시) | 7일 (기본)
     자동 삭제
```

사용자는 언제든 "삭제" 누르면 즉시 삭제 (비동기 아님).

## AI/LLM 보안

- **Zero data retention**: AI Gateway에서 ZDR 지원 모델만 라우팅.
- **컨텍스트 격리**: 한 작업의 본문이 다른 작업의 프롬프트에 들어가지 않는다 (자명하지만 명시).
- **출력 검증**: 모델 출력은 항상 검증 — 본문 외 문자열(시스템 메타) 누출 차단.
- **거절 능력**: 모델이 모르는 정보는 비워두고 사용자에게 묻는다. 지어내지 않는다.
