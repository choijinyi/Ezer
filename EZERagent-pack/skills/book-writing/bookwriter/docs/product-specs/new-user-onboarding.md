# New User Onboarding

```
사용자: 처음 방문한 작가/연구자
문제: 자기 글을 간행본으로 만들고 싶지만 LaTeX/조판 도구를 배우고 싶지 않다
가치: 파일 하나 올리면 5분 안에 PDF 미리보기를 보여준다
```

> **트랙 표기**: 시나리오 A = Track 1 (현재). 시나리오 B = Track 2 (M3 이후).

## Happy path

### 시나리오 A: 새 책 쓰기 (Track 1, 현재 주된 흐름)
1. CLI: `/new --scaffold mybook` → `manuscripts/mybook/`에 14장 스캐폴드 생성
2. 사용자가 `book.json`의 제목/저자 채우고 각 장 `.md` 파일 작성 (필요 없는 장은 삭제 + 매니페스트 정리)
3. CLI: `/new manuscripts/mybook` → job-id 발급, 매니페스트 검증
4. CLI: `/run <job-id>` → ingest → structure 까지 자동
5. 구조 이상이 있으면 `decisions.md`에 질문 게이트, 사용자가 응답
6. CLI: `/run <job-id>`(재실행) → edit → typeset → export
7. `dist/<job-id>/book.pdf` 생성

### 시나리오 B: 기존 글 한 편을 책으로 (Track 2 — 보류)
1. 웹 또는 CLI: `.md` 파일 하나 업로드/지정
2. 시스템이 자동으로 1장짜리 매니페스트로 래핑
3. 이후 시나리오 A의 4–7단계와 동일

목표 시간: 시나리오 B는 첫 빌드까지 **5분 이내**. 시나리오 A는 사용자의 집필 시간이 지배적이며, 빌드 자체는 <3분.

## Edge cases

- **`book.json` 누락** → `--scaffold`로 만들도록 안내, 진행 거절
- **매니페스트가 가리키는 파일이 없음** → 명시적 실패 (조용히 건너뛰지 않음)
- **파일명 케이스 불일치** (Linux/Mac) → 실패 (Windows에서는 통과해도 케이스 정확 매칭 강제 — TI-11)
- **빈 본문 장** → 실패. 빈 frontmatter/backmatter는 통과 + meta 기록.
- **`.md` 외 확장자 입력** → 거절 (v1은 .md만 — Q2 결정)
- **혼합 언어** → 메인 언어 자동 감지, `book.json.lang` 우선
- **장이 14개보다 많거나 적음** → 매니페스트가 진실. 14는 스캐폴드 기본일 뿐 강제 아님 (M1).

## Non-goals

- 회원가입 강제 (게스트로 1건 무료)
- 콘텐츠 생성/요약 (변환만)
- 협업 편집

## 성공 측정

- 첫 빌드 도달률 ≥ 60%
- 미리보기 → 다운로드 전환률 ≥ 30%
- 평균 빌드 시간 < 3분 (50p 기준)
