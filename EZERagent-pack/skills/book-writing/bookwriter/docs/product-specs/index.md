## 작성 가이드

각 스펙 상단:
```
사용자: 누구
문제: 무엇이 불편한가
가치: 우리가 무엇을 다르게 하는가 (한 문장)
```

본문:
- **Happy path** — 이상적 흐름
- **Edge cases** — 무엇이 깨질 수 있나
- **Non-goals** — 일부러 안 하는 것
- **성공 측정** — 무엇이 보이면 성공인가
