## 문서 형식

각 design doc은 다음을 포함한다:
1. **Context** — 왜 이 결정이 필요한가
2. **Options considered** — 무엇을 검토했는가
3. **Decision** — 어떻게 가기로 했는가
4. **Consequences** — 무엇을 포기하는가

ADR(Architecture Decision Record) 스타일을 차용하되, 가벼운 마크다운으로 유지한다.
