# Core Beliefs

bookwriter가 양보하지 않는 원칙들. 이 목록과 충돌하는 기능은 거절하거나 재설계한다.

## 1. 변환기지, 생성기가 아니다
사용자가 제공한 글/논문이 콘텐츠의 원천이다. 우리는 **형식을 바꿀 뿐 사실을 추가하지 않는다.** AI가 누락된 단락을 채우거나 인용을 지어내는 일은 버그다.

## 2. 사람은 결정을, 모델은 반복을
챕터 구조, 표지 시안, 최종 출판은 사람이 승인한다. 문법 교정, 색인 생성, 조판은 모델이 자동으로 한다. 이 경계는 `decisions.md` 게이트로 강제한다.

## 3. 파일이 진실이다
어떤 시점에 작업을 멈추고 파이프를 다시 돌려도 같은 결과가 나와야 한다. 메모리, 캐시, 세션 상태에 결정을 의존시키지 않는다. `build/<job>/` 안의 파일만 보고 어디까지 진행했는지 알 수 있어야 한다.

## 4. 검사 가능한 중간물
중간 산출물은 모두 텍스트(JSON, Markdown, SVG)다. 바이너리 캐시는 디버깅을 막는다. PDF/EPUB은 최종 단계에서만 등장한다.

## 5. 템플릿은 코드 옆에 산다
조판 템플릿은 `templates/`에 있고 버전 관리된다. "디자이너가 워드 파일을 보내줬어요"는 받아들이지 않는다.

## 6. 작은 실패가 큰 실패보다 낫다
한 단계가 깨지면 다음 단계는 차단한다. "어떻게든 PDF를 뽑아내기"보다 "왜 깨졌는지 명시"가 우선이다.
