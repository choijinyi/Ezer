# DESIGN.md

bookwriter의 시각/UX 디자인 원칙. 결과물(간행본)과 도구 자체(웹 앱) 양쪽에 적용된다.

## 1. 활자가 우선이다

간행본 도구의 첫인상은 **타이포그래피**다. 폰트 페어링, 자간, 문단 간격을 기본값에서 절대 양보하지 않는다. UI 컴포넌트는 그 다음.

기본 폰트:
- 본문 한글: Pretendard / Noto Serif KR (선택)
- 본문 영문: Source Serif 4 / Inter
- 코드: JetBrains Mono

## 2. 단계별 미리보기

조판은 추상적이다. 사용자는 매 단계 **무엇이 바뀌었는지 시각적으로** 봐야 한다.
- ingestor 후: 정규화된 마크다운 렌더
- structurer 후: 목차 트리 다이어그램
- typesetter 후: 페이지 썸네일

## 3. 결정 게이트는 거대하게

`decisions.md`의 질문은 화면 중앙에 큰 카드로. "다음" 버튼을 누르려면 의식적인 행동이어야 한다. 작은 토스트/배너로 묻지 않는다.

## 4. 색상은 적게

UI는 모노크롬 + 1개 액센트(잉크 블루 `#1E3A8A`). 간행본 자체는 사용자 색상이므로 도구 UI가 시끄러우면 안 된다.

## 5. 다크 모드는 1급 시민

학술 작업은 밤에 한다. 다크 모드에서 PDF 미리보기는 종이색을 유지한다 (페이지를 검게 칠하지 않는다).

## 컴포넌트 라이브러리

shadcn/ui 기반. 커스텀 컴포넌트는 `components/book/` 아래.

세부는 [FRONTEND.md](FRONTEND.md) 참조.
