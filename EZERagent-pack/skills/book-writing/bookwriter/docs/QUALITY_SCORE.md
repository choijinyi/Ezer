# QUALITY_SCORE.md

간행본의 "좋음"을 측정 가능하게 만든다. 자동 점수 + 휴리스틱 체크리스트의 조합.

## 자동 점수 (CI/빌드 단계)

| 항목 | 측정 | 기준 |
|---|---|---|
| 본문 무결성 | ingestor 입력 vs editor 출력의 의미 보존 (임베딩 코사인) | ≥ 0.97 |
| 인용 보존 | 입력 인용 개수 == 출력 인용 개수 | exact |
| 위젯/과부족 | 페이지 첫/끝 단독 줄 | ≤ 1% 페이지 |
| 깨진 참조 | 끊긴 내부 링크 | 0 |
| 폰트 임베드 | PDF에 임베드된 폰트 | 100% |
| 빌드 시간 | 50p 기준 wall clock | < 3분 |

기준 미달 시 빌드 실패. 사용자에게 자동 통과 금지.

## 휴리스틱 체크리스트 (사람 검수)

조판 단계 후 무작위 페이지 5장 보고:

- [ ] 본문 활자 크기/간격이 편안한가
- [ ] 제목 위계가 시각적으로 명확한가
- [ ] 표/그림 캡션이 대상에 인접한가
- [ ] 페이지 번호/머리글 정보량이 적정한가
- [ ] 첫 페이지(표제지)가 부끄럽지 않은가

3개 이상 "아니오"면 조판 템플릿 자체에 결함. 개별 작업 패치 금지.

## 회귀 골든

`tests/golden/` 아래에 입력 → 기대 PDF 해시를 보관. 템플릿/엔진 업그레이드 시 의도적 변경만 갱신.

```
tests/golden/
├── short-paper-md/
│   ├── input.md
│   ├── expected.pdf.sha256
│   └── expected-pages/   # 페이지별 PNG 비교용
└── ...
```

## "왜 이 점수인가"

자동 점수만으로 충분하지 않다 — 활자는 수치화 어렵다. 휴리스틱만으로 충분하지 않다 — 사람은 회귀를 못 본다. 둘 다 필요하다.
