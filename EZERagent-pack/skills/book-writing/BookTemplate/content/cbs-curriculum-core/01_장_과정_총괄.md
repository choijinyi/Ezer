## 1. 과정 개요

| 항목 | 내용 |
|---|---|
| 과정명 | AI 기반 뉴스 콘텐츠 제작·기사 생성 자동화 실무 (핵심역량교육) |
| 교육 대상 | CBS M&C 콘텐츠 제작 핵심 인력 10명 (편집자·PD·기자) |
| 총 시간 | 80시간 (7회차, 회차당 10~12시간) |
| 교육 목표 | AI 기반 콘텐츠 제작·기사 생성 자동화 역량 확보, AI 도구 활용 실무 프로젝트 수행 능력 습득 |
| 교육 방법 | 이론 강의 + 실습 코드(파이썬) + PBL·CBL 프로젝트 |
| 선수 과정 | 전사교육 「생성형 AI 콘텐츠 제작 실무」 수료 또는 동등 수준 |
| 연계 | PBL/CBL 산출물을 PoC 피드백 루프·AX 실행계획에 직접 반영 |

## 2. 학습 경로

핵심역량교육은 전사교육에서 다진 AI 리터러시를 **실제 자동화 파이프라인 구현**으로 끌어올리는 심화 과정이다.

```
전사교육 40H        핵심역량교육 80H        PoC(현업 검증)        AX 실행계획
이해·기초     ──▶    자동화·실무      ──▶    피드백 루프 3회전  ──▶  전사 확산
                     (본 과정)
```

1~5회차에서 기술 모듈(프롬프트·STT·영상 분석·검색·생성)을 익히고, 6회차 PBL과 7회차 CBL에서 이를 **하나의 파이프라인으로 조립**해 CBS 실제 과제를 해결한다.

## 4. 교육 방법

- **실무 자동화 밀착** — CBS M&C의 실제 업무(노컷TV 채널, 뉴스 음성·영상 아카이브, 기사 DB)를 입력으로 삼아 STT·영상 분석·검색·생성 파이프라인을 만든다.
- **원리 + 재현 가능한 코드** — 각 기술의 동작 원리를 먼저 설명하고, 곧바로 손으로 돌려 볼 수 있는 파이썬 코드를 제공한다.
- **PBL·CBL로 수렴** — 1~5회차의 기술을 6회차 PBL(문제기반학습)·7회차 CBL(도전기반학습)에서 실제 과제 해결로 통합한다.

## 5. 평가 체계 요약

| 평가 요소 | 비중 | 방식 |
|---|:---:|---|
| 출석·참여 | 필수 | 전 회차 80% 이상 참여 |
| 실습 코드 산출물 | 중 | 1~5회차 실습 코드·결과물 |
| PBL 프로젝트 | 상 | 6회차 통합 파이프라인 + 효과 측정(정량) |
| CBL 산출물 | 상 | 7회차 효율화 맵·AI 운용 가이드·피드백 루프 설계 |

> 세부 평가 기준·수료 요건·실습 환경은 **3부 평가·수료·운영**에서 다룬다.
