## 부록 A. 회차별 도구·라이브러리 인덱스

본 교재에 등장한 도구·파이썬 라이브러리를 분야별로 정리한다. 라이브러리 이름·버전·요금·모델명은 빠르게 바뀌므로 **각 공식 문서에서 최신 정보를 확인**하고, 사내 보안·라이선스 정책을 우선한다.

| 분야 | 도구·라이브러리 | 주요 용도 | 관련 회차 |
|---|---|---|---|
| LLM API | `google-genai`(Gemini), `anthropic`(Claude), `openai`(GPT) | 텍스트 생성·요약·분류·구조화 출력 | 1·2·3·4·5 |
| 프롬프트 기법 | system 역할, few-shot, Chain-of-Thought, 구조화 출력(JSON), 프롬프트 체이닝 | 결과 품질·안정성 향상 | 1 (전 회차 활용) |
| 음성(STT) | `whisperx`, `torch`, 화자 분리(diarization), 강제 정렬(alignment) | 뉴스 음성 받아쓰기·타임코드·녹취 | 2 |
| 영상·멀티모달 | Gemini File API(`google-genai`) | 영상 장면 요약·태깅, 영상→텍스트 구조화 | 3 |
| 임베딩·검색 | `sentence-transformers`, `chromadb`/`faiss`, `numpy`, 임베딩 API | 시맨틱 검색·중복 탐지·추천·RAG | 4 |
| 생성·자막 | 이미지·영상 생성 모델, TTS API, `srt` | 숏폼 대본·나레이션·자막 동기화 | 5 |
| 프로젝트 방법론 | PBL(문제기반)·CBL(도전기반), PoC 피드백 루프 | 실무 과제 해결·전사 효율화 설계 | 6·7 |

## 부록 C. 실습 환경 셋업 요약

```bash
# 파이썬 3.10+ 가상환경 권장
python -m venv .venv && source .venv/bin/activate   # (Windows: .venv\Scripts\activate)

# 회차별 핵심 라이브러리 (필요한 것만 설치)
pip install google-genai anthropic openai     # 1~5회차 LLM·TTS API
pip install whisperx                           # 2회차 STT (torch 동반 설치)
pip install sentence-transformers chromadb     # 4회차 임베딩·벡터 검색
pip install srt                                # 5회차 자막(SRT)

# API 키는 코드가 아니라 환경 변수로 (예시)
export GEMINI_API_KEY="..."      # Windows PowerShell: $env:GEMINI_API_KEY="..."
export ANTHROPIC_API_KEY="..."
export HF_TOKEN="..."            # WhisperX 화자 분리 모델용(필요 시)
```

**[주의]** 키를 코드·노트북·저장소에 남기지 않는다. 사내 정책상 외부 API가 제한되면 강사가 안내하는 사내 게이트웨이/대체 환경을 사용한다.

## 부록 D. 핵심 원칙 다시 보기

코드로 업무를 자동화할수록 사람이 지켜야 할 원칙은 더 중요해진다. 모든 회차에 공통으로 적용된다.

1. **사실 확인** — 자동 생성·받아쓰기·요약 결과는 모두 초안이며, 발행 전 검증은 사람의 책임이다(환각·오인식 주의).
2. **저작권·출처** — 음성·영상·이미지의 권리와 상업적 사용 가능 여부, 출처를 확인한다(초상권·음악 포함).
3. **개인정보·보안** — 미공개 취재원·사내 데이터·개인정보를 외부 AI API에 함부로 보내지 않는다. 처리 범위·보관 정책을 먼저 정한다.
4. **검수 게이트** — 자동화 파이프라인이라도 발행 직전에는 반드시 사람이 검수한다.
5. **투명성·재현성** — AI 활용 콘텐츠는 사내 기준에 따라 고지하고, 코드·프롬프트·파라미터를 기록·버전 관리해 같은 결과를 재현할 수 있게 한다.

## 출처 및 근거

- 교육 과정 구성(과정명·대상·목표·80시간 7회차 커리큘럼)은 CBS M&C 혁신바우처 사업계획서의 **핵심역량교육 교육과정**(「AI 기반 뉴스 콘텐츠 제작·기사 생성 자동화 실무」) 절을 근거로 한다.
- 수요기업 현황·병목(콘텐츠 1건당 3~6시간, 소재 탐색 30~50% 병목, 뉴스 영상 아카이브·기사 DB 보유, 노컷TV 채널 등)과 PoC 피드백 루프(3회전)·AX 실행계획 연계 구조는 동 사업계획서를 인용·정리한 것이다.
- 본 교재의 외부 도구·라이브러리·모델의 구체 기능·요금·라이선스는 집필 시점(2026년) 기준이며, 실제 활용 전 각 공식 자료로 재확인이 필요하다.

> **버전·갱신 안내** — 생성형 AI 분야는 변화가 빠르다. 본 교재는 *원리와 파이프라인 구조* 중심으로 구성했으므로, 도구가 바뀌어도 학습 내용의 뼈대는 유효하다. 라이브러리·모델별 최신 사용법은 공식 문서를 함께 참고하라.
