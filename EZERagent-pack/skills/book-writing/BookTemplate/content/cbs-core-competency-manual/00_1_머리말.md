## 이 교재에 대하여

본 교재는 CBS M&C 핵심역량교육 과정 **「AI 기반 뉴스 콘텐츠 제작·기사 생성 자동화 실무」**(총 80시간, 7회차)의 공식 학습 교재다. 전사교육 「AI 리터러시 및 콘텐츠 제작 AI 도구 활용 기초」를 수료한 콘텐츠 제작 핵심 인력(편집자·PD·기자)이 **AI 도구를 직접 다루고, 코드로 업무를 자동화하는 단계**로 올라서는 것이 목표다.

1권(전사교육)이 "AI를 내 도구로 인식하기"였다면, 2권(핵심역량교육)은 **"AI로 내 업무를 자동화하는 파이프라인을 직접 만들기"**다. 그래서 이 교재는 **이론과 실습 코드를 함께** 싣는다.

이 교재는 세 가지 원칙으로 쓰였다.

1. **실무 자동화 밀착** — 일반적인 코딩 강의가 아니라, CBS M&C의 실제 업무(노컷TV 채널, 뉴스 음성·영상 아카이브, 기사 DB)를 입력으로 삼아 STT·영상 분석·검색·생성 파이프라인을 만든다.
2. **원리 + 재현 가능한 코드** — 각 기술의 동작 원리를 먼저 설명하고, 곧바로 손으로 돌려 볼 수 있는 파이썬 코드를 제공한다. 코드는 *복붙용 정답*이 아니라 *내 데이터에 맞게 고쳐 쓰는 출발점*이다.
3. **PBL·CBL로 수렴** — 1~5회차에서 익힌 기술을 6회차 PBL(문제기반학습)과 7회차 CBL(도전기반학습)에서 CBS 실제 과제 해결로 통합한다. 교육 성과가 PoC·AX 실행계획으로 이어지는 구조다.

## 이 교재 사용법

각 회차(장)는 1권과 동일한 구조로 구성된다.

| 구성 | 역할 |
|---|---|
| **학습 목표** | 이 회차를 마치면 할 수 있게 되는 것 |
| **핵심 개념** | 기술의 동작 원리 (왜 그런가) |
| **실습** | 파이썬 코드로 직접 돌려 보는 단계별 과제 |
| **체크리스트** | 회차 목표 달성 여부 자가 점검 |
| **핵심 요약 · 다음 회차 예고** | 한 장 정리와 연결 |
| **핵심 용어** | 회차에 등장한 용어 풀이 |

본문에는 다음 표시가 쓰인다.

- **[개념]** 반드시 이해하고 넘어가야 할 핵심 원리
- **[실습]** 직접 따라 하는 코드 과제
- **[팁]** 실무에서 시간을 줄여 주는 요령
- **[주의]** 특히 조심할 점(사실 확인·저작권·개인정보·API 키 보안 등)

## 실습 환경

- **언어·도구**: 파이썬 3.10+ 기준. 코드는 주피터 노트북·VS Code 어디서든 실행할 수 있다.
- **주요 라이브러리**(회차별 안내): `openai`/`anthropic`/`google-genai`(LLM API), `whisperx`(STT), `sentence-transformers`·`chromadb`/`faiss`(임베딩·벡터 검색) 등.
- **API 키**: 외부 LLM·음성 API는 키가 필요하다. 키는 코드에 직접 쓰지 말고 **환경 변수**로 관리한다(`os.environ`). 키를 파일·저장소에 남기지 않는다.
- 모델·라이브러리 버전과 요금은 빠르게 바뀐다. 본 교재는 *원리와 파이프라인 구조* 중심으로 구성했으므로, 도구가 바뀌어도 학습 내용의 뼈대는 유효하다.

## 자동화 시대에 더 중요해지는 4가지 원칙

코드로 업무를 자동화할수록, 사람이 지켜야 할 원칙은 더 중요해진다. 전 회차에 걸쳐 반복한다.

1. **사실 확인(팩트체크)** — 자동 생성된 기사·요약·자막은 모두 *초안*이다. 발행 전 사실 검증은 사람의 책임이며, 자동화 흐름에도 **사람 검수 게이트**를 반드시 둔다.
2. **저작권·출처** — 학습·생성·재가공에 쓰는 음성·영상·이미지의 권리와 출처, 상업적 사용 가능 여부를 확인한다.
3. **개인정보·보안** — 미공개 취재원, 사내 데이터, 개인정보를 외부 AI API에 무분별하게 보내지 않는다. 민감 데이터는 처리 범위·보관 정책을 먼저 정한다.
4. **투명성·재현성** — AI를 활용한 콘텐츠는 사내 기준에 따라 고지하고, 자동화 코드·프롬프트·파라미터는 누구나 같은 결과를 재현할 수 있도록 기록·버전 관리한다.

이제 1회차에서 출발한다. 우리가 매일 쓰는 LLM이 *내부에서 실제로 무엇을 하는지*부터 깊이 들여다보고, 그 동작 원리를 활용해 결과 품질을 끌어올리는 고급 프롬프트와 API 활용으로 나아가자.
