## 학습 목표

이 회차를 마치면 다음을 할 수 있다.

- AI가 영상 편집의 어떤 단계를 어떻게 돕는지 설명할 수 있다.
- 음성 인식(STT) 기반 **자막 자동 생성·동기화**를 수행하고 교정할 수 있다.
- 긴 영상에서 **하이라이트를 자동 추출**해 숏폼으로 재가공할 수 있다.
- 텍스트 기반 편집의 개념을 이해하고 적합한 도구를 고를 수 있다.

## 1. 핵심 개념

### 1.1 AI는 영상 편집을 어떻게 돕나

**[개념]** AI는 영상 편집을 *대체*하기보다 **반복·시간 소모 작업을 덜어 준다.** 대표적으로 네 가지다.

| 기능 | 설명 | 절감 효과 |
|---|---|---|
| 자동 자막(STT) | 음성을 인식해 자막을 자동 생성·동기화 | 자막 타이핑·싱크 시간 대폭 절감 |
| 텍스트 기반 편집 | 대본 텍스트를 지우면 해당 영상 구간도 삭제 | 컷 편집 진입장벽↓ |
| 자동 하이라이트 | 긴 영상에서 핵심 구간 자동 선별 | 숏폼 소재 발굴 시간↓ |
| 자동 리프레이밍 | 가로 영상을 세로(숏폼)로 자동 변환 | 재편집 공수↓ |

### 1.2 영상 편집 AI 도구 비교

| 도구 | 강점 | 한국어 자막 | 비고 |
|---|---|---|---|
| Adobe Premiere Pro | 전문 편집 + AI 기능(텍스트 기반 편집 등) | 우수 | 사내 사용 중, 기존 워크플로우 연계 |
| Vrew | 자동 자막·텍스트 기반 편집·간편 | 매우 우수 | 국내 뉴스·유튜브에서 널리 사용 |
| CapCut | 자동 자막·템플릿·숏폼 | 우수 | SNS 숏폼 친화 |
| Descript | 텍스트 기반 편집·음성 보정 | 보통 | 팟캐스트·영문 강점 |
| 자동 숏폼 도구 | 긴 영상 → 하이라이트 클립 자동화 | 도구별 상이 | 숏폼 대량 제작 |

**[팁]** 이미 쓰는 프리미어 프로의 AI 기능부터 익히면 기존 워크플로우를 깨지 않고 효율을 올릴 수 있다. 빠른 자막·숏폼은 Vrew 같은 경량 도구가 편하다. **도구를 늘리기 전에 "이미 가진 도구의 AI 기능"을 먼저 쓴다.**

### 1.3 자막 자동 생성·동기화

**[개념]** 흐름은 *음성 → STT로 텍스트 변환 → 타임코드와 함께 자막 생성 → 화면에 동기화*다. 한국어 STT는 많이 정확해졌지만 완벽하지 않다. **오인식 교정**이 핵심 작업이다.

자주 틀리는 부분: 고유명사·외래어, 숫자·단위, 동음이의어, 겹치는 발화, 소음 구간. → 교정 후 사내 자막 스타일(글자 수·위치·줄바꿈)에 맞춘다.

### 1.4 하이라이트 자동 추출과 숏폼

**[개념]** 자동 하이라이트는 발화 밀도·키워드·장면 전환 등을 분석해 "흥미로운 구간"을 후보로 제시한다. 사람이 그중 고르면 도구가 세로 비율 변환·자막 번인까지 처리한다. 단, **무엇이 정말 중요한지는 사람이 판단**한다(맥락·사실관계).

## 2. 업무 워크플로우

### 2.1 자막 워크플로우

| 단계 | 내용 |
|---|---|
| ① 생성 | STT로 전체 자막 자동 생성 |
| ② 교정 | 고유명사·숫자·오인식 수정 |
| ③ 스타일 | 글자 수·위치·줄바꿈을 사내 기준에 맞춤 |
| ④ 번인/내보내기 | 영상에 입히거나 자막 파일로 출력 |

### 2.2 숏폼 양산 워크플로우

원본 영상 → 자동 하이라이트로 클립 후보 → 사람 선별 → 세로 변환·자막 → 썸네일(4회차) → 검수·발행. **노컷TV 채널의 롱폼 자산을 숏폼으로 재활용**하는 데 바로 적용할 수 있다.

## 3. 실습

### [실습 1] 뉴스·인터뷰 영상 자동 자막 + 교정 (50분)

3~5분 영상에 자동 자막을 생성하고 교정한다. 교정 전후의 정확도를 표로 기록한다.

| 항목 | 자동 생성 | 교정 후 |
|---|---|---|
| 고유명사 정확도 | | |
| 숫자·단위 정확도 | | |
| 자막 1줄 글자 수 적정 | | |
| 총 소요 시간 | | |

### [실습 2] 긴 영상에서 숏폼 1편 만들기 (50분)

10분 이상 영상에서 자동 하이라이트로 후보를 뽑고, 1개를 골라 세로 숏폼(30~60초)으로 완성한다. 자동 추천 구간과 본인이 고른 구간이 같은지/다른지 토론한다.

### [실습 3] 텍스트 기반 편집 체험 (30분)

대본 텍스트에서 불필요한 문장을 지워 영상 구간이 함께 잘리는 방식을 체험한다. 전통적 타임라인 편집과 비교해 장단점을 정리한다.

**[주의]** 자동 편집·자막은 **맥락을 모른다.** 발언의 앞뒤를 잘라 의미가 왜곡되지 않는지, 자막 오인식이 오보로 이어지지 않는지 반드시 사람이 검수한다.

## 4. 체크리스트

- [ ] AI 영상 편집의 4가지 도움(자막·텍스트편집·하이라이트·리프레이밍)을 설명할 수 있다.
- [ ] 자동 자막을 생성하고 고유명사·숫자를 교정했다(실습 1).
- [ ] 긴 영상에서 숏폼 1편을 완성했다(실습 2).
- [ ] 텍스트 기반 편집의 장단점을 말할 수 있다.
- [ ] 자동 편집 시 맥락 왜곡을 막기 위한 검수의 필요성을 이해했다.

## 5. 핵심 요약

- AI는 자막·하이라이트·리프레이밍 같은 **반복 작업**을 덜어 준다.
- 자동 자막은 **교정**이, 자동 하이라이트는 **사람의 선별**이 품질을 좌우한다.
- 이미 쓰는 도구(프리미어)의 AI 기능부터 익히고, 숏폼은 경량 도구를 병행한다.
- 노컷TV 롱폼 자산의 숏폼 재활용에 곧바로 적용할 수 있다.
