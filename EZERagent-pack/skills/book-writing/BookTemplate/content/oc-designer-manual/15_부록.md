> **'탈모' 관련 — 별도 강조**
>
> 메뉴명·상담·안내·SNS 어디에도 **'탈모 치료·개선·예방·발모' 표현을 절대 쓰지 않습니다.** 탈모 증상 완화 표기는 식약처 심사를 받은 기능성화장품에만 허용됩니다. 우리 메뉴는 "두피 집중 관리", "두피 환경 케어"로만 표현합니다. 의학적 상담이 필요해 보이는 고객에게는 전문의 상담을 권합니다 — 샵에서 진단하지 않습니다.

## C. 시술 전 공통 체크리스트

모든 시술 공통. 시술별 세부 체크는 각 장의 프로토콜을 따릅니다.

- [ ] **차트 확인** — 이전 시술 이력·레시피·특이사항·민감 이력 확인 (첫 방문이면 신규 차트 개설)
- [ ] **두피 진단** — 타입(지성/건성/민감/복합), 상처·염증 유무 (상처·염증 시 해당 부위 시술 보류)
- [ ] **모발 진단** — 손상 등급, 다공성, 신생부/기시술부 경계 (화학 시술 시 필수)
- [ ] **패치테스트·이력 확인** — 염모제 시술 첫 방문 고객 패치테스트 이력 확인, 임신·수유 여부 확인
- [ ] **도구 소독** — 커트 도구·빗·클립 등 고객별 소독 상태 확인
- [ ] **사진 합의** — 원하는 스타일·예상 결과 범위를 사진으로 합의 (컬러·펌·블랙빼기 필수)
- [ ] **시간 안내** — 총 소요 시간 사전 안내 (복합·장시간 시술 필수)
- [ ] **O 프리케어 준비** — O 제품·도포 도구 준비, 오늘 케어 포함 안내 멘트
- [ ] **촬영 동의** — Before/After 기록이 필요한 시술은 촬영 동의 확인

## D. 이상 반응 대응 카드

상황이 발생하면 아래 순서를 그대로 따릅니다. 판단을 미루지 않는 것이 원칙입니다.

**① 따가움·화끈거림 호소 (염색·탈색·펌 약제 중)**

1. 즉시 시술 중단
2. 해당 부위 약제를 미온수로 충분히 세척
3. 상태 확인 후 고객에게 상황 설명 (병명 추정·자가 진단 발언 금지)
4. 증상이 가라앉지 않으면 전문의 상담 권유
5. 차트에 발생 시각·부위·조치 기록 → 다음 시술 설계에 반영

**② 탄력 급락 (탈색·블랙빼기 중 모발이 껌처럼 늘어남)**

1. 즉시 중단, 잔여 약제 세척
2. 목표 명도 미달이어도 시술을 이어가지 않는다
3. 고객에게 모발 상태와 중단 사유를 설명하고 회차 분할 재설계
4. 클리닉 케어로 전환 제안, 차트 기록

**③ 화상 의심 (열펌·매직 기기, 스티머)**

1. 즉시 해당 기기·롯드 제거, 냉각
2. 피부 상태 확인 — 붉음·통증 지속 시 시술 중단
3. 필요시 의료기관 안내 (자가 처치·연고 제안 금지)
4. 발생 경위와 조치를 차트·매장 기록으로 남김

**④ 알레르기 의심 (가려움·부어오름·발진)**

1. 즉시 중단·세척
2. 전문의 상담 권유 (증상 심하면 즉시 의료기관 안내)
3. 사용 제품명·부위·시각을 차트에 기록
4. 이후 방문 시 해당 성분 시술 여부를 반드시 재확인

> 공통 원칙: **중단이 손해가 아니다.** 무리하게 이어간 시술 한 번이 고객과 매장 모두에게 훨씬 큰 비용이 됩니다.
