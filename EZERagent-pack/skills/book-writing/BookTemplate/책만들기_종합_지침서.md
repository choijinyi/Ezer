# 책 만들기 종합 지침서

> Markdown → HTML → PDF(Playwright Chromium) 파이프라인을 활용한 책 제작 가이드
> 지원 판형: 신국판(152×225mm) / B5(188×257mm) — 빌드 시 선택

---

## 1. 프로젝트 폴더 구조

새 책을 만들 때 아래 구조를 그대로 복사하여 사용합니다.

```
BookTemplate/
│
├── books.py               ← 책별 메타 + 챕터 매핑의 단일 진실 원천 (새 책은 여기 등록)
├── build_book.py          ← 빌드 스크립트 (content/<책이름>/ → HTML → PDF)
├── convert_manuscript.py  ← 원본 원고 → content/<책이름>/ 변환 (간지 삽입 등)
├── build.bat              ← Windows 더블클릭 실행용
├── requirements.txt       ← 필요 라이브러리 목록
│
├── templates/
│   ├── base.html          ← HTML 뼈대 (표지 + 본문 wrapper)
│   └── style.css          ← 전체 디자인 스타일시트 (Jinja2로 판형·테마 주입)
│
├── content/               ← 책별 마크다운 원고 (책마다 하위 폴더로 격리)
│   └── <책이름>/
│       ├── 00_목차.md
│       ├── 01_장_제목.md
│       └── ...
│
├── images/                ← 표지·본문 이미지 (본문 도판은 images/figures/)
│
└── output/                ← 빌드 결과물 (기본 출력 경로)
    ├── book_preview.html
    └── 책이름_판형_타임스탬프.pdf
```

## 2. 필수 파일 목록 및 역할

### 2-1. 시스템 파일 (책마다 재사용)

| 파일 | 역할 | 수정 필요 여부 |
|------|------|---------------|
| `build_book.py` | Markdown→HTML→PDF 빌드 | 책 제목/부제/저자/출력경로만 수정 |
| `build.bat` | Windows 더블클릭 실행 | 수정 불필요 |
| `requirements.txt` | Python 패키지 | 수정 불필요 |
| `templates/base.html` | HTML 뼈대 | 수정 불필요 (범용) |
| `templates/style.css` | 전체 디자인 | 디자인 변경 시 수정 |

### 2-2. 콘텐츠 파일 (책마다 새로 작성)

| 파일명 패턴 | 용도 | 필수 여부 |
|-------------|------|-----------|
| `00_0_추천사.md` | 추천사 | 선택 |
| `00_0a_감사의글.md` | 감사의 글 | 선택 |
| `00_1_프롤로그.md` | 프롤로그/서문 | 선택 |
| `00_목차.md` | 목차 (속지 + 본문) | **필수** |
| `01_장_제목.md` ~ `10_장_제목.md` | 본문 각 장 | **필수** |
| `11_에필로그.md` | 에필로그 | 선택 |
| `12_부록.md` | 부록 | 선택 |

## 3. 파일 이름 규칙 (매우 중요)

> **현재 빌드 순서는 `books.py`의 `chapters` 리스트 순서**를 따릅니다(파일명 정렬 아님).
> 아래 zero-padding 규칙은 폴더 안에서 사람이 순서를 읽기 좋게 하는 관례로 계속 지킵니다.

### 핵심 규칙

1. **숫자 2자리로 zero-padding** — `01_`, `02_`, ... `10_` (1자리 `1_`은 안 됨)
2. **전면부(Front Matter)** — `00_`으로 시작, 세부 순서는 `00_0_`, `00_0a_`, `00_1_`
3. **본문** — `01_` ~ `10_` (또는 그 이상)
4. **후면부(Back Matter)** — `11_`, `12_` 등

### 정렬 순서 예시

```
00_0_추천사.md        ← 가장 먼저
00_0a_감사의글.md     ← "0a"가 "0_" 다음, "1_" 이전
00_1_프롤로그.md      ← 프롤로그
00_목차.md            ← 목차 (00_ 중 마지막 = "목" > "0","1")
01_장_...md           ← 1장
02_장_...md           ← 2장
...
10_장_...md           ← 10장
11_에필로그.md        ← 에필로그
12_부록.md            ← 부록
```

### 원하는 순서가 다를 경우

감사의 글을 맨 뒤로 보내고 싶다면 `13_감사의글.md`로 변경합니다.
순서는 파일명의 숫자 접두어로 100% 제어합니다.

## 4. 콘텐츠 파일 작성법

### 4-1. 장 속지 (간지) — HTML 블록

각 장(또는 프롤로그/에필로그/부록/추천사/감사의글) 파일의 **맨 위**에 아래 HTML을 넣습니다.
이 부분이 파란 배경의 간지 페이지로 렌더링됩니다.

```html
<div class="chapter-title-page">
<div class="chapter-title-inner">
<p class="chapter-label">CHAPTER</p>
<p class="chapter-number">1</p>
<div class="chapter-title-divider"></div>
<p class="chapter-title-text">장 제목 첫째 줄<br>장 제목 둘째 줄</p>
<div class="chapter-verse">
<p class="chapter-verse-text">"성경 구절 내용<br>두 번째 줄"</p>
<p class="chapter-verse-ref">— 성경 책명 장:절</p>
</div>
</div>
</div>
```

#### 라벨(chapter-label) 종류

| 섹션 | chapter-label 값 | chapter-number |
|------|-------------------|----------------|
| 추천사 | `RECOMMENDATION` | `&nbsp;` (빈칸) |
| 감사의 글 | `ACKNOWLEDGMENTS` | `&nbsp;` |
| 프롤로그 | `PROLOGUE` | `&nbsp;` |
| 1~10장 | `CHAPTER` | `1` ~ `10` |
| 에필로그 | `EPILOGUE` | `&nbsp;` |
| 부록 | `APPENDIX` | `&nbsp;` |

> **주의**: 숫자가 없는 섹션은 반드시 `<p class="chapter-number">&nbsp;</p>` 사용

### 4-2. 본문 — 마크다운

간지 HTML 아래에 마크다운으로 본문을 작성합니다.

```markdown
# 1장
## 제자는 '배우는 사람'이 아니라 '따르는 사람'이다

본문 텍스트...

## Ⅰ. 첫 번째 대주제

본문 텍스트...

### 1. 소주제

본문 텍스트...

> 인용문 블록

**굵은 글씨**, *이탤릭*

- 목록 항목
- 목록 항목

1. 순서 목록
2. 순서 목록

---

### 묵상과 적용

**돌아보기**

1. 질문 1
2. 질문 2

**실천하기**

- 실천 항목

*마무리 이탤릭 문장*
```

#### 마크다운 문법 요약

| 요소 | 마크다운 | 비고 |
|------|----------|------|
| 장 제목 | `# 1장` | 새 페이지 시작 |
| 절 제목 | `## Ⅱ. 제목` | 하단 구분선 자동 |
| 소제목 | `### 1. 제목` | |
| 단락 | 빈 줄로 구분 | 자동 들여쓰기 |
| 굵게 | `**텍스트**` | |
| 기울임 | `*텍스트*` | |
| 인용문 | `> 텍스트` | 왼쪽 세로선 + 배경색 |
| 순서 목록 | `1. 항목` | |
| 비순서 목록 | `- 항목` | |
| 수평선 | `---` | 본문에서 비표시(CSS) |
| 이미지 | `![캡션](images/파일.png)` | |
| 강제 줄바꿈 | `<br>` | 간지 제목에서 사용 |

### 4-3. 목차 파일 (00_목차.md) 작성법

목차 파일은 두 부분으로 구성됩니다.

#### Part 1: 목차 속지

```html
<div class="toc-title-page">
<p class="toc-title-label">CONTENTS</p>
<p class="toc-title-heading">목 차</p>
<div class="toc-title-divider"></div>
<p class="toc-title-subtitle">부제목 텍스트</p>
</div>
```

#### Part 2: 목차 본문

```html
<div class="toc">

<h2>목차</h2>

<!-- 전면부 항목 -->
<div class="toc-entry toc-front">
<span class="toc-entry-title">추천사</span>
<span class="toc-entry-dots"></span>
<span class="toc-entry-page">2</span>
</div>

<!-- 섹션 구분선 (빈 여백) -->
<div class="toc-section"></div>

<!-- 장 항목 (굵은 글씨) -->
<div class="toc-entry toc-chapter">
<span class="toc-entry-title">1장&nbsp;&nbsp;&nbsp;장 제목</span>
<span class="toc-entry-dots"></span>
<span class="toc-entry-page">17</span>
</div>

<!-- 섹션 구분선 -->
<div class="toc-section"></div>

<!-- 후면부 항목 -->
<div class="toc-entry toc-back">
<span class="toc-entry-title">에필로그 — 부제</span>
<span class="toc-entry-dots"></span>
<span class="toc-entry-page">122</span>
</div>

</div>
```

#### 목차 항목 클래스

| 클래스 | 용도 | 스타일 |
|--------|------|--------|
| `toc-front` | 전면부 (추천사, 감사의 글, 프롤로그) | 회색 글씨 |
| `toc-chapter` | 본문 장 | **굵은 글씨** |
| `toc-back` | 후면부 (에필로그, 부록) | 회색 글씨 |

#### 페이지 번호 확인 방법

1. 먼저 임의의 페이지 번호로 빌드
2. PDF에서 실제 페이지 번호 확인
3. 목차 파일의 페이지 번호 수정
4. 다시 빌드하여 최종 확인

> 목차가 1페이지 → 2페이지로 넘어가면 이후 모든 페이지가 1씩 밀리므로 주의

## 5. 새 책 등록 포인트 — books.py

새 책을 만들 때는 `build_book.py`가 아니라 **`books.py`의 `BOOKS` 딕셔너리에 항목을 추가**합니다.

```python
BOOKS = {
    "my-new-book": {
        "title": "책 제목",              # <br> 로 표지 줄바꿈 가능
        "subtitle": "부제목",
        "author": "저자명",
        "pdf_filename": "책_제목.pdf",   # 빌드 시 판형·타임스탬프가 뒤에 붙음
        "cover": {
            "mode": "tech-navy",         # 또는 "image" + "image": "표지파일.png"
            "kicker": "상단 소제목",     # tech-navy 전용(선택)
            "badge": "AI",               # tech-navy 전용(선택)
        },
        "chapters": [
            # (원본파일, 출력파일, 라벨, 번호, 제목, 구절, 구절출처)
            # 원본파일=None 이면 손으로 유지하는 파일(예: 목차)
            (None,            "00_목차.md",     None,      None,     None,     None, None),
            ("01-chapter.md", "01_장_제목.md",  "CHAPTER", "1",      "제목",   "",   ""),
        ],
    },
}
```

원고는 `content/<책이름>/` 폴더에 넣습니다.

## 6. style.css 디자인 커스터마이징

### 6-1. 페이지 크기 변경

```css
@page {

    margin: 20mm 18mm 25mm 18mm;  /* 상 우 하 좌 */
}
```

### 6-2. 간지(장 속지) 색상 변경

현재는 파란 배경 + 흰 글씨입니다. 다른 색으로 바꾸려면:

```css
.chapter-title-page {
    background-color: #2b4c7e;   /* ← 배경색 변경 */
}
.chapter-label { color: rgba(255,255,255,0.7); }   /* 라벨 */
.chapter-number { color: #ffffff; }                  /* 숫자 */
.chapter-title-text { color: #ffffff; }              /* 제목 */
.chapter-verse-text { color: rgba(255,255,255,0.75); } /* 구절 */
.chapter-verse-ref { color: rgba(255,255,255,0.55); }  /* 레퍼런스 */
.chapter-title-divider { background-color: rgba(255,255,255,0.4); } /* 구분선 */
.chapter-title-page::before,
.chapter-title-page::after { background-color: rgba(255,255,255,0.35); } /* 장식선 */
```

| 분위기 | 배경색 | 설명 |
|--------|--------|------|
| 네이비 블루 | `#2b4c7e` | 현재 (차분한 신뢰감) |
| 딥 그린 | `#2d5a3d` | 자연/성장/치유 |
| 버건디 | `#6b2d3e` | 격조/고전적 |
| 차콜 | `#3a3a3a` | 모던/미니멀 |
| 다크 퍼플 | `#3d2b5a` | 영성/묵상 |
| 따뜻한 브라운 | `#5a4030` | 편안함/클래식 |

## 7. 새 책 만들기 — 단계별 워크플로

### Step 1: 프로젝트 복사

```
MyBook_Project/ 폴더를 통째로 복사
→ NewBook_Project/ 로 이름 변경
→ content/ 폴더 안의 .md 파일 모두 삭제
```

### Step 2: books.py에 책 등록

```python
BOOKS["새-책-이름"] = {
    "title": "새 책 제목", "subtitle": "새 부제목", "author": "저자명",
    "pdf_filename": "새_책.pdf", "cover": {...}, "chapters": [...],
}
```

### Step 3: 원고 작성

1. 원본 초고 파일(텍스트)을 준비
2. 각 장마다 content/ 폴더에 .md 파일 생성
3. 파일 상단에 간지 HTML 블록 작성
4. 그 아래에 마크다운 본문 작성

### Step 4: 목차 작성

1. `00_목차.md` 파일에 속지 + 본문 HTML 작성
2. 페이지 번호는 임시로 채움

### Step 5: 첫 빌드 & 페이지 번호 확인

```
python build_book.py <책이름> --output output --page-size 2
```

> **주의**: `echo "" | python build_book.py` 처럼 stdin을 파이프하지 마세요.
> PowerShell에서 파이프하면 BOM이 섞여 입력이 깨집니다. 반드시 `--output`/`--page-size` 플래그를 쓰세요.

1. PDF 열어서 각 장 시작 페이지 확인
2. 목차 파일의 페이지 번호 수정
3. 다시 빌드 → 페이지 번호 최종 확인

### Step 6: 디자인 조정 (선택)

- 간지 색상 변경 → style.css 수정
- 표지 색상 변경 → style.css 수정
- 폰트/크기 변경 → style.css 수정
- 빌드 → 확인 → 반복

## 8. 환경 설정

### 필수 소프트웨어

| 항목 | 설명 |
|------|------|
| Python 3.8+ | Anaconda 환경 권장 |
| pip 패키지 | `pip install markdown jinja2 playwright` |
| 브라우저 | `playwright install chromium` (최초 1회) |
| 한글 폰트 | Noto Serif KR (설치 필요) |

### 렌더링(Playwright Chromium) 주의사항

1. **렌더링 엔진은 Chromium** — flexbox 등 최신 CSS 사용 가능 (예: `.photo-grid`)
2. **가운데 정렬** — `text-align: center` + `margin: 0 auto` 조합
3. **@page 규칙** — 각 페이지 유형별로 별도 정의 (cover, toc, chapter-title 등)
4. **page-break** — `page-break-before: always`로 새 페이지 시작
5. **배경색 출력** — 빌드 스크립트가 `print_background=True`로 처리(이미 설정됨)

### 빌드 명령어

```bash
# 터미널에서 (비대화형 — 권장)
cd 프로젝트폴더
python build_book.py <책이름> --output output --page-size 2   # 1=신국판, 2=B5

# 대화형 (질문에 직접 답할 때만)
python build_book.py <책이름>

# 또는 build.bat 더블클릭 (기본 책을 대화형으로 빌드)
```

## 10. 자주 하는 실수 & 해결법

| 문제 | 원인 | 해결 |
|------|------|------|
| 10장이 1장 앞에 나옴 | 파일명 `1_장` vs `10_장` 정렬 | `01_장`으로 zero-padding |
| 간지 숫자가 안 보임 | `chapter-number`에 값 누락 | 빈칸은 `&nbsp;` 사용 |
| 간지 내용이 가운데 안 됨 | flexbox 사용 | `display: block` + `text-align: center` |
| 목차 페이지 번호 틀림 | 목차 자체가 페이지 수 변경 | 빌드 후 확인 → 수정 → 재빌드 |
| 장 시작이 새 페이지 안 됨 | `# 제목`이 h1으로 변환 안 됨 | 간지 HTML 뒤 빈 줄 확인 |
| 한글 깨짐 | 인코딩 문제 | 파일 UTF-8 저장, build_book.py에 인코딩 설정 있음 |
| 이미지 안 나옴 | 경로 오류 | 본문 도판은 `../images/figures/파일명` 상대경로 사용 |
| 목록이 문단으로 뭉개짐 | 목록 앞에 빈 줄 없음 | 목록 시작 전 반드시 빈 줄 삽입 |
| PDF에 배경색 안 나옴 | 배경 출력 설정 | 빌드 스크립트가 `print_background=True`로 처리(기본 해결) |
