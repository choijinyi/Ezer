에제르(Ezer) — 히브리어로 “도움, 돕는 자, 조력자”.
이 AI는 사람을 대신하는 존재가 아니라, 사람이 하는 일을 곁에서 돕는 조력자라는 뜻으로 이름 붙였습니다. 직업이나 분야를 가리지 않습니다.
1단계

먼저 내 컴퓨터에 맞는 것을 받으세요

현재 최신 버전은 v0.13.17입니다. 셋 중 하나만 받으시면 됩니다.

파일이 좀 큽니다 — 이유가 있습니다. 책 만들기 기능이 들어 있습니다. 원고를 쓰고 → 편집하고 → 인쇄용 PDF까지 나오는 과정을 에제르가 도와줍니다. 신국판(에세이·단행본)과 B5(교재·실무서) 두 판형을 고를 수 있습니다.

여기에 출판용 한글 글꼴(KoPubWorld·본명조)이 함께 들어가서 파일이 커졌습니다. 글꼴이 있어야 인쇄소에 넘길 수 있는 품질로 조판됩니다. 한 번만 받으시면 됩니다.

개념

에제르는 무엇이 다른가요

챗GPT 같은 AI는 한 사람과 대화하는 창구입니다. 에제르는 여러 명의 AI를 한 팀으로 묶어 여러분의 지시를 나눠 처리합니다.

🗣️

말하듯 부탁하면 됩니다

“이 보고서 초안 3장 분량으로 정리해줘”처럼 평소 말투 그대로 적으시면 됩니다. 외울 명령어가 없습니다.

👥

여러 AI가 나눠서 일합니다

지휘하는 AI, 실제로 글을 쓰는 AI, 그 결과를 검토하는 AI가 따로 있습니다. 혼자 쓴 글보다 검토를 거친 글이 낫습니다.

📚

기능이 처음부터 들어 있습니다

글쓰기·조사·통계·영상·개발·생활 행정까지 220가지 기능이 설치와 함께 갖춰집니다. 따로 등록할 것이 없습니다.

🔒

자료가 밖으로 나가지 않습니다

기록과 통계는 여러분 컴퓨터 안에만 저장됩니다. 업무 자료나 개인 기록처럼 민감한 내용에 중요한 부분입니다.

✋

중요한 일은 반드시 물어봅니다

위험하거나 되돌릴 수 없는 작업은 AI가 스스로 하지 않고 허락을 구하는 창을 띄웁니다.

🧠

쓸수록 나를 알아갑니다

문체, 자주 쓰는 표현, 일하는 방식을 기억해 두고 다음 작업에 반영합니다.

꼭 기억하실 것 — 에제르는 조력자입니다. 결과물의 최종 책임은 언제나 그것을 쓰는 사람에게 있습니다. AI가 만든 글은 반드시 사실과 대조해 확인하신 뒤 사용하세요. 에제르는 이 점을 스스로도 지키도록 만들어져 있어서, 근거 없는 단정을 피하고 출처를 밝히도록 설계돼 있습니다.
2단계

설치하기

준비물은 인터넷 연결 하나뿐입니다. 전체 10분이면 끝납니다.

윈도우에서

  1. 내려받은 setup.exe 파일을 두 번 누릅니다.
  2. 파란 경고창이 뜹니다. “Windows의 PC 보호” — 놀라지 마세요. 추가 정보를 누르고 실행을 누르시면 됩니다. (아래 문제 해결에 이 창이 왜 뜨는지 적어 두었습니다.)
  3. 다음을 눌러 설치를 마칩니다.
  4. 바탕화면에 생긴 아이콘을 두 번 누릅니다. 첫 실행은 30초쯤 걸립니다.

맥에서

  1. 내려받은 dmg 파일을 두 번 누릅니다.
  2. 에제르 아이콘을 Applications 폴더로 끌어다 놓습니다.
  3. 처음 열 때만 — 아이콘을 오른쪽 클릭해서 열기를 선택하세요. 그냥 두 번 누르면 “개발자를 확인할 수 없다”며 막힙니다.
  4. 30초쯤 기다리시면 화면이 뜹니다.

예전 버전 깨끗이 지우고 새로 설치하기

예전 버전이 남아 이상하게 동작할 때만 하시면 됩니다. 처음 설치하시는 분은 건너뛰세요.

윈도우에서 완전히 지우기
  1. 에제르를 완전히 종료합니다. (상단바 ⏻ 종료 버튼을 쓰시면 뒤에 도는 것까지 함께 내려갑니다.)
  2. 설정 → 앱 → 설치된 앱에서 EZERagent를 제거합니다.
  3. PowerShell에 아래를 붙여 넣고 실행합니다. 
    schtasks /delete /tn EZERagentd /f
Remove-Item "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\EZER-start.cmd" -Force -ErrorAction SilentlyContinue
Remove-Item "$env:LOCALAPPDATA\EZERagent" -Recurse -Force -ErrorAction SilentlyContinue
  4. 여기까지는 프로그램만 지웁니다. 설정과 기억은 %USERPROFILE%\.EZERagent 에 그대로 남아 다시 설치해도 이어집니다 — 보통은 이게 맞습니다(그동안 쌓은 기억을 잃지 않습니다). 설정이 꼬여서 지우고 다시 까는 것이라면 그것까지 지워야 증상이 사라집니다. 
    Remove-Item "$env:USERPROFILE\.EZERagent" -Recurse -Force -ErrorAction SilentlyContinue
    되돌릴 수 없습니다 — 아래 '무엇이 지워지나' 참고.
  5. 컴퓨터를 다시 켠 뒤 새로 설치합니다.
맥에서 완전히 지우기
  1. 에제르를 종료합니다. (상단바 ⏻ 종료 버튼 권장)
  2. 응용 프로그램에서 EZERagent를 휴지통으로 옮깁니다.
  3. 터미널에 아래를 붙여 넣고 실행합니다. 
    launchctl unload ~/Library/LaunchAgents/com.EZERagent.EZERagentd.plist
rm -f ~/Library/LaunchAgents/com.EZERagent.EZERagentd.plist
rm -rf ~/.local/state/EZERagent
  4. 여기까지는 프로그램만 지웁니다. 설정과 기억은 ~/.EZERagent 에 그대로 남아 다시 설치해도 이어집니다 — 보통은 이게 맞습니다(그동안 쌓은 기억을 잃지 않습니다). 설정이 꼬여서 지우고 다시 까는 것이라면 그것까지 지워야 증상이 사라집니다. 
    rm -rf ~/.EZERagent
    되돌릴 수 없습니다 — 아래 '무엇이 지워지나' 참고.
  5. 새로 설치합니다.
'완전 초기화'가 지우는 것 — 되돌릴 수 없습니다. .EZERagent 폴더에는 프로그램이 아니라 여러분의 것이 들어 있습니다: 에제르가 쌓아 온 장기기억, 하던 작업의 진행 상태와 할 일 목록, 직접 만들거나 고친 스킬·설정입니다. 프로그램을 다시 깔아도 이것들은 돌아오지 않습니다. 증상이 설정 때문이라고 확인된 경우에만 지우세요. 그냥 새 버전을 쓰고 싶은 것이라면 이 폴더를 남겨 두는 편이 낫습니다 — 업데이트는 기억을 지우지 않습니다.

설치하면 이런 것들이 자동으로 갖춰집니다

기반 프로그램 Node.js · 파이썬 · git — 설치 파일에 들어 있습니다. 따로 받으실 것 없습니다.
AI 프로그램 Claude Code 등 — 첫 실행 때 자동으로 설치됩니다.
기능 220가지 자동으로 인식됩니다. 등록 절차가 없습니다.
여기서 한 가지는 반드시 직접 하셔야 합니다 — AI 계정 로그인.
화면이 뜨면 Claude(앤트로픽) 계정으로 로그인하라는 안내가 나옵니다. 유료 구독이 있어야 에제르가 실제로 일합니다. 이 로그인이 안 되면 아무 대답도 하지 않습니다.

책 만들기를 쓰시려면 — 두 가지만 더 설치하세요

원고를 인쇄용 PDF로 조판하는 데 Pandoc과 Typst가 필요합니다. 책을 만들 때만 쓰이니, 당장 필요 없으면 건너뛰셔도 됩니다.

윈도우 — 두 줄이면 됩니다 
winget install --id JohnMacFarlane.Pandoc
winget install --id Typst.Typst
맥 — 한 줄이면 됩니다 
brew install pandoc typst

처음 열었을 때 이렇게 하세요

  1. 안내 창을 따라 넘기고, 작업할 폴더를 고릅니다. 여기에 에제르가 만든 원고와 파일이 쌓입니다.
  2. “에제르시작”이라고 적고 보냅니다. 지휘 담당·작업 담당·검토 담당 AI가 함께 준비되고, 220가지 기능이 연결됩니다.
  3. 평소 말투로 부탁합니다. 아래 예시처럼 적으시면 됩니다.
  4. 결과가 마음에 안 들면 그냥 말하세요. 다시 시켜도 됩니다.

파일은 어디에 저장되나요

에제르가 만든 원고·보고서는 지금 작업 중인 폴더에 그대로 저장됩니다. 상단 파일 버튼을 누르면 그 폴더의 파일 목록이 보이고, 눌러서 한글이나 워드로 여시면 됩니다.

에제르는 다섯 명의 AI가 한 팀으로 움직입니다. 각자 맡은 일이 다릅니다.

검토자를 둘이나 두는 이유는 쓴 사람과 채점하는 사람을 나누기 위해서입니다.

이럴 때 팀으로 쓰시면 좋습니다

  • 보고서·기획안을 여러 편 한꺼번에 준비할 때
  • 자료 조사 · 원고 작성 · 검토를 동시에 진행하고 싶을 때
  • 완성한 원고를 다른 관점에서 따져 보고 싶을 때
  • 시간이 오래 걸리는 조사를 맡겨 두고 다른 일을 하고 싶을 때

진행 상황이 궁금하시면 “지금 진행 상황 알려줘” · “다 됐어?”라고 물으시면 됩니다.

AI가 허락을 구할 때

중요한 작업 앞에서 에제르는 스스로 실행하지 않고 승인 요청을 띄웁니다. 화면 위쪽에 표시가 뜨면 허용이나 거부를 고르시면 됩니다.

요청을 오래 그냥 두면 AI가 그 자리에서 멈춰 기다립니다. 대답이 없다 싶으면 컨트롤 센터 → 승인 Feed를 확인해 보세요.
기술을 다루실 분을 위한 명령어

곁에 기술을 도와주실 분이 있다면 이 부분을 보여주세요. 터미널에서 직접 다룰 수 있습니다.

EZERagent status              # 전체 상황 한눈에
EZERagent doctor --fix        # 자기진단 후 수리
EZERagent boot                # 표준 팀 일괄 기동
EZERagent send --to worker "상태 보고해줘"
EZERagent send-key --to worker Return
EZERagent feed list --status pending
EZERagent pause / resume      # 전체 정지·재개

전체 명령은 EZERagent actions, 자세한 설명은 사용 설명서에 있습니다.

문제 해결

이럴 때는 이렇게 하세요

설치할 때 파란 경고창이 떠요 (윈도우)

정상입니다. “Windows의 PC 보호”라는 창인데, 추가 정보 → 실행을 누르시면 됩니다.

유료 코드 서명 인증서를 아직 붙이지 않아서 뜨는 창입니다. 프로그램 문제가 아닙니다.

“손상되었기 때문에 열 수 없습니다” (맥)

파일이 망가진 게 아닙니다. 0.13.14 버전부터 고쳐졌으니 최신 버전을 다시 받으시면 됩니다.

그래도 뜨면 터미널에 아래를 넣어 보세요.

xattr -cr /Applications/EZERagent.app
“개발자를 확인할 수 없어” (맥)

아이콘을 오른쪽 클릭 → 열기 → 다시 열기. 처음 한 번만 하시면 됩니다.

화면이 안 뜨거나 멈춘 것 같아요

처음 실행은 30초쯤 걸립니다. 수백 개 파일을 자리에 놓는 중입니다.

1분이 넘도록 그대로면 앱을 완전히 끄고 다시 켜 보세요. 그래도 안 되면 EZERagent doctor --fix를 아는 분께 부탁하세요.

아무 대답이 없어요
  1. 로그인부터 확인하세요. 가장 흔한 원인입니다. Claude 계정 로그인은 직접 한 번 하셔야 합니다.
  2. 승인 요청이 밀려 있는지 — 컨트롤 센터 → 승인 Feed.
  3. 입력 중이면 기다립니다. 사람이 타이핑 중이면 AI가 3초간 기다립니다.
  4. 정지 상태일 수 있습니다. “다시 시작해줘”라고 하시거나 EZERagent resume.
AI가 사실이 아닌 내용을 말해요

반드시 확인하셔야 합니다. 특히 인용문, 숫자, 역사적 사실, 통계는 그대로 믿지 마세요.

이렇게 요청하시면 됩니다.

  • “출처 밝혀줘” → 근거를 함께 제시합니다
  • “팩트체크 해줘” → 검증 기능이 작동합니다
  • “이거 확실해? 다시 확인해줘” → 교차 검증합니다

그럼에도 내보내기 전 사람의 최종 확인을 대신할 수 있는 것은 없습니다.

글이 너무 길어요 / 문체가 안 맞아요

그냥 말씀하시면 됩니다. “절반으로 줄여줘” · “처음 읽는 사람도 알아들을 말로” · “결론을 더 구체적으로”.

매번 같은 말을 반복하기 번거로우시면 — “앞으로 보고서는 항상 이런 문체로 써줘”라고 일러두시면 기억해 두고 다음부터 반영합니다.

대화가 길어지니 AI가 헤매요

AI의 기억 용량에 한계가 있습니다. 에제르는 60%에 이르면 스스로 저장·정리한 뒤 이어 갑니다.

새 주제로 넘어가실 때는 ⌘/Ctrl+T로 새 작업 화면을 여시는 편이 낫습니다.

컴퓨터가 갑자기 느려졌어요

에제르가 실행한 프로그램이 쌓였을 수 있습니다. 5초마다 점검하는 자동 정리 장치가 있지만, 컨트롤 센터 → Live 탭에서 CPU·메모리를 직접 확인하실 수 있습니다.

앱을 끄면 하던 작업이 사라지나요?

사라지지 않습니다. 창을 닫아도 뒤에서 도는 본체가 작업을 이어 갑니다. 컴퓨터를 완전히 껐다 켠 뒤에는 “이어서 하자”라고 하시면 재개합니다.

정말 완전히 끄고 싶으시면 상단바의 ⏻ 종료 버튼을 쓰세요. 저장 신호를 보낸 뒤 뒤에서 도는 것까지 모두 내리고 창을 닫습니다.

0.13.17 버전부터는 AI 화면들이 쓰던 프로그램(클로드코드 등)까지 함께 내려갑니다. 그 전 버전에서 종료 뒤에도 프로세스가 남으셨다면 아래 항목을 보세요.

⏻ 종료를 눌렀는데 프로세스가 계속 돌아요

0.13.17 버전에서 고쳤습니다. 그 전까지는 종료를 눌러도 두 가지가 남았습니다.

  1. AI 화면들이 쓰던 프로그램이 살아남았습니다. 본체가 내려가면 그 안에서 돌던 클로드코드·코덱스 같은 프로그램도 같이 꺼질 것이라고 보았는데, 실제로는 부모가 꺼져도 자식이 따라 꺼지지 않는 경우가 있었습니다.
  2. 이쪽이 주된 원인입니다 — 컴퓨터가 본체를 되살렸습니다. 설치할 때 에제르는 "꺼져 있으면 다시 켜라"는 항목으로 등록됩니다(맥은 launchd, 윈도우는 작업 스케줄러). 재부팅 뒤에도 알아서 켜지게 하려는 장치인데, 바로 이것이 종료 버튼으로 내린 본체까지 맥은 10초, 윈도우는 1분쯤 뒤에 되살려 놓았습니다.

지금은 종료 버튼이 AI 화면들과 그 프로그램을 먼저 닫고, 되살리는 항목을 이번 한 번만 내린 뒤 본체를 끕니다. 다음에 에제르를 켜면 자동 기동은 그대로 살아납니다 — 지우는 것이 아닙니다.

이미 돌고 있는 것은 이렇게 처리하세요.
새 버전을 설치하고 ⏻ 종료를 한 번 누르면 그때부터 적용됩니다. 지금 떠 있는 본체는 아직 예전 코드로 돌고 있어서, 설치만으로는 멈추지 않습니다.

그래도 남는 것 같으면 아래로 확인해 보세요. 아무것도 나오지 않으면 제대로 내려간 것입니다.

# 맥
launchctl list | grep EZERagent

# 윈도우 (PowerShell)
schtasks /query /tn EZERagentd
묻지도 않았는데 상태 보고가 자꾸 올라와요

예전 버전은 마스터가 주기적으로 노드들에게 생존을 묻고 그 결과를 화면에 올렸습니다. 지금은 처음 켤 때 한 번만 보고하고, 그 뒤로는 물어보실 때만 답합니다 — "상태 알려줘" · "다 살아 있어?" · "진행 상황"처럼 말씀하시면 그때 전체를 점검해 보고합니다. (문제가 생겼을 때 오는 경고는 그대로 받습니다 — 멈춘 노드나 자원 부족은 여전히 바로 알려 드립니다.)

업데이트를 받으셨는데도 보고가 계속 올라온다면, 예전에 깔린 주기 알림 설정이 남아 있어서입니다. 이 설정만은 업데이트가 덮어쓰지 않습니다(직접 추가하신 알림을 지우지 않으려는 안전장치입니다). 마스터에게 "하트비트 두 개 꺼줘"라고 말씀하시거나, 아래를 직접 실행하시면 됩니다.

EZERagent schedule remove owner-progress-report-5min
EZERagent schedule remove owner-progress-report-15min

재시작은 필요 없습니다 — 30초 안에 반영됩니다.

업데이트는 어떻게 하나요?

화면 위쪽 업데이트 자리에 표시가 나타납니다.

  • ! — 프로그램 자체가 새로워졌습니다. 누르면 설치하고 다시 시작합니다. 하던 작업은 자동으로 복원됩니다.
  • ↻ — 기능만 갱신됩니다. 재시작이 없습니다. 하던 일이 끊기지 않습니다.

고쳐 쓰신 설정은 업데이트가 지우지 않습니다. 보존해 두고 새 버전을 옆에 놓아둡니다.

에제르는 15분마다 새 버전이 있는지 확인합니다. 표시가 뜨면 그때 누르시면 됩니다.

민감한 내용을 넣어도 되나요?

기록과 통계는 여러분 컴퓨터 밖으로 나가지 않습니다. 다만 대화 자체는 AI 회사(Claude) 서버를 거칩니다. 이 점은 분명히 아셔야 합니다.

안전하게 쓰시려면:

  • 실명은 최소화하세요 (김OO 님처럼)
  • 건강·재정 같은 민감정보는 되도록 적지 마세요
  • 컨트롤 센터 세션 탭의 🔒 가림 기능을 쓰시면 기록에서 개인정보가 가려집니다
비용이 드나요?

에제르 자체는 무료입니다. MIT 라이선스 오픈소스입니다.

비용은 Claude 유료 구독료에서만 발생합니다. 얼마나 쓰고 있는지는 컨트롤 센터 → 비용·효율 탭에서 하루·주간 단위로 보실 수 있습니다.

알려진 한계
▸ 윈도우 설치 때 경고창이 뜹니다 (유료 코드 서명 인증서 미적용)
▸ 그래픽카드·NPU 실시간 표시는 맥(M1 이후)에서만 됩니다
▸ 안전장치는 탐지·정지 층이지 암호학적 방어가 아닙니다
▸ 비밀정보 검사기는 알려진 형태만 걸러냅니다

이상하다 싶으면 “에제르가 이상해, 진단해줘”라고 하시면 스스로 점검합니다. 그래도 안 되면 ezer.agent@gmail.com로 알려 주세요.

강의 실습

오늘 직접 해보실 순서

  1. 파일을 설치하고 아이콘을 실행합니다.
  2. 안내 창을 넘기고 Claude 계정으로 로그인합니다.
  3. “안녕”이라고 적어 보고 대답이 오는지 확인합니다.
  4. 손에 있는 자료를 놓고 “이 내용 요약해줘”라고 부탁합니다.
  5. 결과를 고쳐 봅니다. “더 짧게” · “근거를 구체적으로”
  6. 이어서 “이걸로 보고서 초안 만들어줘”라고 계속 부탁해 봅니다.
  7. “출처 밝혀줘”로 근거를 확인합니다.
  8. 컨트롤 센터를 열어 Live와 비용 탭을 봅니다.
  9. ⌘/Ctrl+G로 큰 글씨 화면으로 바꿔 봅니다.
  10. “에제르시작”이라고 선언해 팀이 구동되는 것을 확인합니다.
